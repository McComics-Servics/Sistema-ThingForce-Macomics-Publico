# Compendio de errores SketchUp McComics 901-950

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

901. Grupos importados desde IFC traen coordenadas extremadamente grandes (km)

Solución: normalizar la geometría trasladando al origen antes de operar.


902. HtmlDialog ignora oninput si el input tiene máscara de formato numérico

Solución: capturar cambios con keyup + sanitizar.


903. El cálculo de volumen falla cuando el sólido contiene cavidades internas no conectadas

Solución: segmentar sólidos internos y sumarlos por separado.


904. Las piezas duplicadas mediante “Move + Ctrl” pierden atributos booleanos

Solución: serializar atributos antes del duplicado.


905. Exportar DXF crea líneas overlapped que duplican longitudes en cálculos posteriores

Solución: filtrar líneas duplicadas con tolerancia de 0.01 mm.


906. HtmlDialog se borra parcialmente cuando el usuario rota la vista 3D muy rápido

Solución: throttle de repintado (50 ms).


907. Las booleanas fallan si el sólido contiene edges colapsados por escalado previo

Solución: reconstrucción de geometría con cleanup.


908. Undo/Redo en escenas complejas rompe la referencia al componente seleccionado

Solución: refrescar selección vía timer.


909. Multiplicar componentes espejo genera definiciones con transformaciones degeneradas

Solución: regenerar Definition nueva para casos espejo.


910. El zoom se vuelve hiper-sensible si el FOV fue modificado externamente

Solución: restaurar FOV a valor estándar (35°–45°).


911. HtmlDialog pierde el valor de un slider cuando el usuario hace scroll rápido

Solución: debouncing en evento “input”.


912. El cálculo de ejes del mueble falla cuando el componente tiene cara base non-planar

Solución: detectar plano dominante usando promedio de normales.


913. Exportar imagen a gran resolución produce bandas verticales por falta de buffer

Solución: dividir render en tiles.


914. Scene tabs personalizados ocultan actualizaciones del plugin

Solución: forzar actualización de cámara tras cambio de escena.


915. Importar .3ds genera caras con doble orientación

Solución: invertir normales según ángulo promedio.


916. HtmlDialog no permite pegar texto si el usuario tiene desactivado el Clipboard en OS

Solución: fallback manual vía input invisible.


917. Llamar a model.commit_operation dentro de un observer provoca corrupción del modelo

Solución: usar timers para salir del observer.


918. Carpetas con nombres muy largos rompen la carga de catálogos

Solución: limitar longitud máxima a 80 caracteres.


919. Componentes con texturas de 1 píxel × 1 píxel se estiran caóticamente

Solución: generar textura mínima de 16x16.


920. HtmlDialog no conserva estado al minimizar SketchUp en pantallas múltiples

Solución: restaurar tamaño y posición al abrir.


921. El plugin falla al leer archivos JSON con comillas tipográficas (“ ”)

Solución: reemplazar por comillas ASCII.


922. Piezas importadas vienen con puntos de pivote rotados 0.00001° causando desajustes

Solución: redondear quaternion o rotación.


923. Exportar BOM a CSV en Mac introduce saltos de línea CR-only

Solución: forzar UTF-8 con CRLF explícito.


924. HtmlDialog produce freeze si se cargan más de 300 thumbnails sin paginación

Solución: lazy-loading de imágenes.


925. Bounding box interno se recalcula mal si la pieza es un arco parcial

Solución: incluir puntos cardinales en el cálculo.


926. Undo no revierte atributos si el diccionario fue creado dentro de un observer

Solución: diferir escritura con timer.


927. Al unir piezas con FollowMe, las aristas se duplican en los bordes interiores

Solución: limpieza automática post-FollowMe.


928. Texturas PBR grandes (4 mapas) saturan VRAM en PCs antiguas

Solución: reducir mapas o usar compresión.


929. HtmlDialog bloquea scroll cuando un contenedor usa overflow-x:auto

Solución: manejar scroll manual en JS.


930. Importar DWG genera capas vacías que afectan el rendimiento del Outliner

Solución: eliminar capas sin entidades.


931. El plugin calcula mal la dirección frontal si el componente tiene normals inconsistentes

Solución: escoger normal más frecuente.


932. Exportar STL con piezas muy largas produce inversión de normales en extremos

Solución: subdividir la pieza en segmentos.


933. HtmlDialog pierde eventos cuando el usuario cambia idioma del teclado

Solución: identificar teclas por keyCode, no letra.


934. Al explotar un componente con subgrupos, se pierden materiales internos

Solución: copiar materiales antes de explotar.


935. Archivos .skp muy antiguos (SketchUp 6–7) rompen lectura de atributos actuales

Solución: conversión previa automática.


936. El plugin interpreta mal el origen del mueble si el componente tiene eje rotado + desplazado

Solución: reconstruir origin desde transform inversa.


937. HtmlDialog deja artefactos gráficos si el usuario activa ClearType

Solución: CSS con font-smoothing neutral.


938. Scripts Ruby fallan en Windows si la ruta contiene caracteres chinos

Solución: normalizar Unicode NFKD antes de usar.


939. Exportar escenas borra transiciones personalizadas del usuario

Solución: almacenar transición y restaurar al terminar.


940. Componente se “encoge” si su escala interna era negativa y se hace un mirror externo

Solución: recalcular matriz final con determinante positivo.


941. HtmlDialog deja de mostrar tooltips en botones cuando se cambian estilos muy rápido

Solución: reconstruir DOM del tooltip.


942. Al agrupar múltiples piezas, las capas asignadas se mezclan incorrectamente

Solución: agrupar por layer única y luego redistribuir.


943. Exportar imagen con textura repetida rompe cuando SketchUp usa modo “Fast Feedback”

Solución: desactivar Fast Feedback temporalmente.


944. El plugin calcula mal el largo útil cuando hay rebajes internos

Solución: medir a partir del contorno real, no del bounding.


945. HtmlDialog se vuelve lento si hay más de 20 inputs numéricos activos

Solución: unificar eventos con delegation.


946. Archivos con millares separadores (1,000.25) rompen el parser numérico interno

Solución: eliminar comas previo a parseo.


947. Piezas gigantes (>50m) generan errores de precisión al colocar guías

Solución: recalcular guías en unidades normalizadas.


948. Si el usuario edita un componente dentro de otro, las coordenadas globales se interpretan mal

Solución: transformar puntos a world coords antes.


949. Exportar PDF desde vista 3D produce sombras pixeladas excesivamente duras

Solución: suavizar sombras previo a export.


950. HtmlDialog pierde acceso al clipboard si el antivirus del usuario bloquea WebView

Solución: detección temprana + fallback con input de texto oculto.
