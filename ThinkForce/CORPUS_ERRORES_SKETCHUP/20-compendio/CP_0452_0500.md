# Compendio de errores SketchUp McComics 452-500

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

452. Duplicación invisible de componentes al regenerar un mueble

Causa: add_instance ejecutado más de una vez por timers duplicados.
Solución: Usar semáforos de control (@creating = true).


453. Pérdida de los laterales del mueble durante escalado inteligente

Causa: Bounding recalculado tarde.
Solución: Recalcular dimensiones antes de aplicar scaling.


454. Cajones que flotan por error acumulado en floats

Causa: Operaciones repetidas.
Solución: Redondear a 3–4 decimales.


455. Toolbar McComics® no aparece al recargar en Windows 11

Causa: Nombre del toolbar cambia mínimamente.
Solución: Usar nombre fijo .freeze.


456. HtmlDialog abre detrás de SketchUp

Causa: CEF reordena ventanas.
Solución: dialog.set_size + always_on_top.


457. Crash al cerrar HtmlDialog mientras un timer sigue ejecutando

Causa: Timer llama a una referencia destruida.
Solución: Validar dialog.visible?.


458. Recargador McComics® daña archivos grandes al sobrescribirlos

Causa: OneDrive o antivirus interrumpe la escritura.
Solución: Guardar en archivo temporal → mover.


459. Exportar CSV genera comas extra en números

Causa: Configuración regional.
Solución: Formato con "%.2f" y reemplazo de comas.


460. Mueble con dimensiones negativas por mal input HTML

Causa: UI permite valores negativos.
Solución: Forzar .abs.


461. Timer infinito provoca alto uso de CPU

Causa: repeat = true.
Solución: Detener ID de timer manualmente.


462. Botón “Crear mueble” duplicado en la UI por multi-carga del HTML

Causa: HTML cargado dos veces.
Solución: Guard variable JS: window.McComics_Initialized.


463. Inputs HTML envían caracteres invisibles

Causa: Caracteres Unicode.
Solución: Sanitizar: .strip + .gsub.


464. Ejes del usuario alterados afectan posiciones de piezas

Causa: Ejes rotados.
Solución: Transformar vectores por model.axes.


465. Rutas de logs fallan cuando hay caracteres especiales

Causa: Paths unicode.
Solución: Normalizar con Pathname.cleanpath.


466. Guías invisibles quedan en el modelo después de crear muebles

Causa: No se borran ConstructionLines.
Solución: Guardar referencias → borrar.


467. Botón WhatsApp falla por URL sin escapar

Causa: Espacios no codificados.
Solución: CGI.escape(url).


468. Piezas repetidas en Despiece por iteración incorrecta

Causa: Iterar entidades sin filtrar grupos.
Solución: entities.grep(Sketchup::Group).


469. Definiciones anónimas dificultan depuración

Solución: definition.name = "McComics*Panel*#{id}".


470. Observer “zombie” sigue recibiendo eventos

Causa: No remover observer.
Solución: remove_observer.


471. Bounding box incorrecto tras escala ~1.0

Causa: Escalas tipo 0.9999.
Solución: Normalizar scaling.


472. CSS rompe la UI por rutas absolutas

Solución: Incrustar CSS en base64.


473. Texturas desaparecen al recargar plugin

Causa: Materiales no refrescan.
Solución: materials.refresh.


474. Crear geometría dentro de grupos bloqueados

Causa: Grupo locked = true.
Solución: Validar antes de crear.


475. look_at falla por normales invertidas

Solución: face.reverse!.


476. abort_operation deja entidades huérfanas

Causa: Falta de limpieza.
Solución: Borrar entidades antes de abortar.


477. HtmlDialog deja de recibir mensajes tras minimizar

Causa: Bug CEF.
Solución: Forzar ping vía JS.


478. Grips interactivos producen fugas de memoria

Causa: No limpiar grips.
Solución: @grips.clear.


479. Muebles gigantes corrompen cámara

Solución: Limitar dimensiones.


480. CSV pierde caracteres UTF-8

Solución: Guardar con encoding: "UTF-8".


481. persistent_id llamado antes de crear instancia

Causa: Definition sin instancias.
Solución: Crear antes de leer ID.


482. Tool se rompe si usuario cambia selección en medio

Solución: Validar @target.valid?.


483. Metadata perdida porque se guardó en definition

Solución: Guardarla en instancia.


484. Atributo leído con clave incorrecta

Solución: Siempre usar constantes para keys.


485. Piezas “se van al infinito” por multiplicar transform en orden incorrecto

Solución: Tpos _ Tscale _ Trot.


486. HTML bloqueado por restricciones CSP

Solución: JS externo, no inline.


487. HtmlDialog no guarda tamaño/posición

Solución: Guardar en Sketchup.write_default.


488. Timer colisiona con undo

Causa: Timer ejecuta operación dentro de otra.
Solución: Ignorar si active_operation != "".


489. Muebles con dimensiones 0 producen crash

Solución: Validar ≥ 1mm.


490. Botón “Más información” con URL desnormalizada

Solución: Validar URI.parse.


491. Material aplicado en cara equivocada por normals invertidos

Solución: Reorientar antes de aplicar.


492. Duplicación de grips en componentes duplicados

Solución: Grips por instancia, no por definition.


493. Cache inconsistente después de recargar

Causa: Cache global.
Solución: Recalcular al recargar plugin.


494. Piezas pequeñas pierden precisión (<10 mm)

Solución: Convertir mm → m → mm con redondeo.


495. Colisión fallida por bounding box en local space

Solución: Transformar corners a world space.


496. Carpeta McComicsPlugins creada varias veces

Solución: Comprobar Dir.exist?.


497. Undo rompe tool por falta de resume

Solución: Implementar método resume.


498. Offsets negativos generan piezas invertidas

Solución: Convertir offset a .abs.


499. Arrays que llegan de JS como strings

Solución: JSON.parse.


500. Rescues silenciosos que ocultan errores críticos

Solución: Siempre loggear e.full_message.

🔥 ERRORES 551–600 551. HtmlDialog deja de actualizar porque el usuario activa “Hardware Acceleration Off”

Síntoma:
Los botones dejan de responder.

Solución:
Detectar en Ruby si CEF no está disponible y reiniciar diálogo.
