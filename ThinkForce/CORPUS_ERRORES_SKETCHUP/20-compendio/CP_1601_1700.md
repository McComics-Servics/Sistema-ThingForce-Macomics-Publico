1601. HtmlDialog no actualiza el color de fondo cuando el sistema cambia entre Light/Dark Mode automáticamente

Solución: escuchar prefers-color-scheme y actualizar vía JS.


1602. Exportar DXF pierde polilíneas cuando comparten el mismo punto final y SketchUp las fusiona internamente

Solución: separar vértices duplicados antes del export.


1603. Importar SKP desde iPad produce materiales HEIF no compatibles

Solución: convertir HEIF → PNG.


1604. Booleanas union fallan cuando sólidos tienen curvas suavizadas con radios casi iguales pero no exactos

1606. Exportar STL triangula incorrectamente si el sólido tiene subdivisión automática de SketchUp activa

1607. Importar OBJ con coordenadas de vértice extremadamente grandes genera deformaciones internas

1608. Undo no revierte escalado si fue aplicado a entidades seleccionadas dentro de un componente abierto

1609. HtmlDialog muestra bordes blancos entre contenedores cuando el sistema baja a 60% de zoom

1610. Exportar PNG ignora sombras suaves (soft shadows) en GPUs antiguas

1611. Importar SKP con geometría colapsada produce errores al medir bounding

1612. Booleanas subtract producen caras “espejo” cuando la topología interna está invertida
