# Compendio de errores SketchUp McComics 1001-1100

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

1001. HtmlDialog pierde valores numéricos cuando el usuario utiliza teclado numérico externo (Numpad)

Causa: keyCodes diferentes a los esperados.
Solución: mapear ambos sets de keyCodes.


1002. Piezas con biseles internos generan “self-intersections” en booleanas

Solución: suavizar edges internos antes de operar.


1003. Importar modelos FBX crea geometría con normales rotadas 90°

Solución: corregir normales mediante análisis vectorial.


1004. HtmlDialog no hace scroll en Mac cuando se usa Magic Mouse

Solución: habilitar eventos wheel con deltaY.


1005. La herramienta no detecta “hover” si el frame rate baja bajo 20 FPS

Solución: limitar cálculos gráficos intensivos.


1006. Exportar DXF omite círculos si están compuestos por más de 128 segmentos

Solución: forzar conversión a arco DXF.


1007. Piezas extremadamente delgadas (0.1 mm) desaparecen al extruir

Solución: usar grosor mínimo permitido por SU.


1008. HtmlDialog pierde clase CSS activa cuando el usuario navega entre tabs internas

Solución: restaurar estado via localStorage.


1009. Undo ignora la eliminación de layers creadas automáticamente por el plugin

Solución: encapsular creación de layers dentro de operaciones.


1010. Importar archivos STEP produce bounding boxes incorrectos

Solución: recalcular bounding desde geometría real.


1011. Las booleanas fallan en piezas con caras casi coplanares (±0.01 mm)

Solución: separar ligeramente geometrías antes.


1012. HtmlDialog no carga íconos .ico en sistemas antiguos

Solución: convertir a PNG base64.


1013. Al mover componentes con MoveTool, la herramienta propia interpreta el movimiento como nuevo click

Solución: filtrar eventos duplicados por timestamps.


1014. Exportar PNG con fondo transparente causa halos blancos alrededor de los bordes

Solución: pre-blur leve + anti-halo.


1015. Importar OBJ genera materiales duplicados con sufijo “\_1”, “\_2”, etc.

Solución: fusionar materiales equivalentes.


1016. HtmlDialog se hace gigantesco si el CSS tiene % en contenedores principales

Solución: usar unidades vh/vw.


1017. El usuario con DPI 125% altera la posición de grips 3D

Solución: escalar grips según devicePixelRatio.


1018. Partes generadas con FollowMe producen caras internas invisibles

Solución: borrar loop interior luego del FollowMe.


1019. Exportar STL produce geometría invertida cuando el componente está rotado en eje arbitrario

Solución: normalizar transform antes de export.


1020. HtmlDialog ignora inputs cuando el usuario activa Sticky Keys (Windows)

Solución: manejar keydown repetidos.


1021. Piezas alineadas a ejes globales pierden referencia si el usuario rota todo el modelo

Solución: consolidar transform a world space.


1022. Exportar DXF revienta si algún texto contiene emojis

Solución: reemplazar caracteres no ASCII.


1023. Importar SKP antiguos conserva capas eliminadas hace años

Solución: purgar capas fantasma previo a cargar.


1024. HtmlDialog toma más de 800 ms en abrir cuando carga muchas fuentes personalizadas

Solución: limitar fonts a 1 principal.


1025. Undo deja “dust geometry” si se rompe una operación a mitad del proceso

Solución: usar abort_operation con limpieza previa.


1026. Importar componentes con geometría curva produce UVs al revés

Solución: Proyectar UV según vector promedio.


1027. HtmlDialog no acepta Drag&Drop sobre inputs en modo oscuro

Solución: CSS: background-color: transparent.


1028. Exportar escenas elimina estilos temporales que el plugin había aplicado

Solución: re-aplicar estilo tras export.


1029. Al seleccionar componentes muy rápidos, SketchUp ignora onSelectionChanged

Solución: hacer pooling de selección con timer.


1030. Booleanas intersect fallan cuando dos sólidos tienen caras casi idénticas

Solución: desplazar ligeramente uno de los sólidos.


1031. HtmlDialog no responde al primer click después de estar oculto

Solución: activar dialog.bring_to_front.


1032. Importar glTF produce sombras erradas por falta de normal map

Solución: reconstruir normales suavizadas.


1033. Exportar JPG usa compresión alta por defecto que degrada calidad

Solución: usar PNG o aumentar calidad manual.


1034. Piezas con offsets negativos generan geometría invertida

Solución: clamping de offset ≥ 0.


1035. HtmlDialog crea scroll vertical eterno si un DIV no calcula height correctamente

Solución: CSS fijo + resize observer.


1036. Al cambiar la escala del modelo completo, se distorsionan transformaciones locales

Solución: reconvertir transform a matriz uniforme.


1037. Importar múltiples SKP dentro del mismo modelo crea definiciones redundantes

Solución: detectar duplicados por GUID.


1038. HtmlDialog parpadea en Mac cuando la GPU está en modo ahorro

Solución: forzar aceleración parcial via CSS.


1039. Booleanas subtract producen cortes incompletos si la pieza tiene triángulos degenerados

Solución: limpiar triangulación previa.


1040. Exportar DXF con polilíneas abiertas produce errores de interpretación

Solución: cerrar polilíneas o convertir a líneas.


1041. HtmlDialog bloquea input si el usuario usa IME (teclado japonés/chino)

Solución: manejar eventos compositionstart y compositionend.


1042. El plugin interpreta mal bounding box si el componente está escalado ≠ 1 en ejes distintos

Solución: usar bounding con transform.worldscale.


1043. Importar curvas desde DWG genera cientos de segmentos que ralentizan todo

Solución: suavizar curva con tolerancia mayor.


1044. HtmlDialog tarda en cargar listas largas (>500 items)

Solución: virtual scrolling.


1045. Exportar imágenes muy grandes crea archivos corruptos cuando supera el buffer

Solución: exportar en tiles o limitar resolución.


1046. Pequeños cilindros triangulados generan hasta 1000 caras invisibles

Solución: simplificar cilindros antes de operar.


1047. HtmlDialog ignora eventos Wheel cuando el usuario usa Touchpad en Linux

Solución: normalizar eventos wheel/touch.


1048. Exportar STL falla si la pieza está compuesta por grupos anidados

Solución: convertir grupos a geometría consolidada.


1049. Importar archivos con geometría hueca crea sólidos no manifold

Solución: rellenar caras faltantes o dividir sólido.


1050. HtmlDialog deja de responder cuando el usuario arrastra una ventana externa encima de él

Solución: reactivar focus con timer cada 300 ms.


1051. HtmlDialog pierde la alineación cuando el usuario cambia el zoom del sistema operativo (125%, 150%)

Solución: escalado relativo usando vw, vh, rem.


1052. Exportar DXF omite curvas si el archivo tiene más de 32.000 vértices

Solución: dividir polilíneas gigantes.


1053. Piezas que se escalan en negativo generan inversión de UV en un solo eje

Solución: re-normalizar UV después de cada escala negativa.


1054. Undo deja texturas mal posicionadas si position_material se aplicó usando view incorrecto

Solución: usar view activo antes de aplicar.


1055. HtmlDialog pierde animaciones CSS si la GPU está saturada

Solución: fallback sin animaciones.


1056. Importar SKP desde versiones viejas deja metadata con claves corruptas

Solución: filtrar diccionarios que no sean strings.


1057. Al agrupar piezas durante un timer activo, se produce “operation nested too deep”

Solución: pausar timers antes de comenzar operaciones.


1058. Exportar STL ignora materiales y genera sólidos sin orientación clara

Solución: recalcular normales antes del export.


1059. Insertar componentes desde un archivo externo con escalas personalizadas distorsiona dimensiones

Solución: normalizar transform antes de insertar.


1060. HtmlDialog no respeta el valor inicial de select si se crea dinámicamente

Solución: esperar a que el DOM cargue antes de setear valor.


1061. Piezas con caras trianguladas internamente producen lectura de área doble

Solución: limpiar diagonales invisibles antes.


1062. Exportar JPG ignora gamma del monitor y genera imágenes más oscuras

Solución: corrección gamma previa (1.2–1.4).


1063. Al insertar piezas demasiado lejos del origen, SketchUp crea jitter visual

Solución: recentrar pieza temporalmente cerca del origen.


1064. HtmlDialog no captura inputs cuando el usuario usa teclado Bluetooth lento

Solución: capturar eventos “input” además de keydown.


1065. Piezas importadas desde Rhino contienen curvas racionales que rompen UV mapping

Solución: convertir curvas a no-racionales.


1066. Exportar DXF causa errores cuando las capas contienen caracteres Unicode complejos

Solución: sanitizar layer.name a ASCII.


1067. El motor booleano falla cuando ambos sólidos comparten una arista completa

Solución: separar geometrías 0.1 mm.


1068. HtmlDialog pierde el foco si el usuario hace Alt+Tab mientras carga contenido

Solución: forzar dialog.bring_to_front.


1069. Al medir bounding box de componentes inclinados, SketchUp usa el bounding global

Solución: calcular bounding orientado (OBB).


1070. Exportar PNG a alta resolución produce saturación del GPU en laptops

Solución: export en tiles pequeños.


1071. Importar Collada (.dae) produce entidades “component_instance” sin definition válida

Solución: regenerar definitions antes de usar.


1072. HtmlDialog muestra bordes no deseados cuando se habilita Windows Classic Theme

Solución: CSS reset total: \* { border:0 !important; }.


1073. Undo borra entidades temporales necesarias para cálculos posteriores

Solución: marcar entidades temporales con atributo y preservarlas.


1074. Al usar move! en puntos flotantes muy pequeños, SketchUp produce valores NaN

Solución: redondear coordenadas antes del move.


1075. Exportar DXF con polilíneas de grosor genera resultados no compatibles con AutoCAD

Solución: convertir a líneas simples sin grosor.


1076. HtmlDialog ignora onblur cuando el contenedor tiene overflow:hidden

Solución: mover inputs fuera del contenedor.


1077. Al crear geometría muy fina, el motor de SketchUp colapsa aristas en puntos únicos

Solución: aumentar escala ×10 durante la creación.


1078. Piezas creadas con ciertos métodos Ruby incluyen “soft edges” invisibles

Solución: endurecer edges antes de finalizar.


1079. Exportar STL produce objetos huecos si los sólidos comparten vértices coincidentes

Solución: fusionar vértices antes del export.


1080. HtmlDialog no captura eventos Touch en PC con pantalla táctil

Solución: implementar listeners touchstart/move/end.


1081. Importar STEP genera superficies NURBS que SketchUp discretiza mal

Solución: aplicar tessellation controlada.


1082. Exportar imágenes falla si el usuario tiene permisos restringidos en la carpeta destino

Solución: guardar primero en carpeta temporal local.


1083. Undo mezcla cambios de dos operaciones si un timer ejecuta código en medio

Solución: bloquear timers dentro de operaciones.


1084. Piezas con ejes personalizados se miden mal al usar transform.inverse

Solución: usar matriz absoluta world_to_local.


1085. HtmlDialog ignora z-index si el elemento padre no tiene “position: relative”

Solución: asegurar posicionamiento relativo.


1086. Exportar DXF ignora líneas ocultas aunque el usuario las necesita

Solución: activar temporalmente “view.hidden_geometry = true”.


1087. Importar OBJ gigantes devuelve múltiples materiales vacíos (sin textura)

Solución: eliminar materiales sin uso.


1088. Piezas curvas calculan mal el “largo útil” por no seguir arco real

Solución: usar longitud de curva real, no bounding.


1089. HtmlDialog re-bota al centro si se intenta mover demasiado rápido

Solución: throttling de eventos drag.


1090. Exportar PDF ignora capas de SketchUp y mezcla todo el contenido

Solución: export en capas separadas.


1091. Undo pierde el “active_path” si el usuario está editando un subgrupo profundo

Solución: recrear context después de undo.


1092. Importar DXF a veces descarta arcos pequeños (<1 mm)

Solución: duplicar tamaño temporalmente para preservar.


1093. HtmlDialog no muestra imágenes WebP en algunos CEF viejos

Solución: convertir WebP a PNG base64.


1094. Exportar JPG hace clipping si el Field of View es muy bajo

Solución: elevar FOV temporalmente.


1095. Booleanas union fallan si hay caras con ángulo menor de 1° entre ellas

Solución: suavizar caras antes de unir.


1096. HtmlDialog desactiva botones si se hace resize mientras hay animación activa

Solución: desactivar animaciones en resizing.


1097. Piezas gigantes distorsionan la cámara debido a near/far plane automáticos

Solución: ajustar planos manualmente.


1098. Exportar STL convierte curvas suaves en polígonos demasiado burdos

Solución: aumentar resolución de triangulación.


1099. HtmlDialog se queda “transparente” si la GPU falla al aplicar compositing

Solución: reiniciar CSS con opacity/visibility.


1100. Importar SKP con estilos personalizados trae configuraciones que rompen cálculos internos

Solución: restablecer estilo base antes de procesar.
