# Compendio de errores SketchUp McComics 1201-1300

1201. HtmlDialog pierde el tab seleccionado si se reconstruye el DOM completo

Solución: almacenar activeTab y restaurarlo tras el update.


1202. Exportar DXF ignora textos alineados verticalmente (rotación 90° invertida)

Solución: convertir texto a contorno vectorial antes.


1203. Importar SKP que contenga “Shadow Strings” personalizados rompe el cálculo de iluminación

Solución: resetear shadow_info al cargar.


1204. Booleanas fallan si los sólidos tienen vértices extremadamente cercanos (<0.001 mm)

Solución: fusionar vértices antes de operar.


1205. HtmlDialog no muestra tooltips si el usuario usa “Modo Simplificado de Accesibilidad”

Solución: forzar tooltip mediante div personalizado.


1206. Exportar STL desde componentes con escala no uniforme produce distorsión del mesh

Solución: bake de transform antes del export.


1207. Importar OBJ con varios materiales genera definitions duplicadas por cada material

Solución: combinar materials antes de generar instancias.


1208. Undo pierde la referencia del último componente creado si existía un SelectionObserver activo

Solución: suspender observer durante operaciones críticas.


1209. HtmlDialog no recibe eventos si la ventana se mueve durante una animación CSS

Solución: pausar animaciones durante drag/move.


1210. Exportar PNG con zoom extremo genera imágenes pixeladas por escalado interno

Solución: forzar super-sampling 2×.


1211. Importar SKP con escenas animadas cambia la cámara de modo inesperado

Solución: resetear cámara tras cargar modelo.


1212. Booleanas de resta eliminan piezas completas cuando el sólido de corte se solapa demasiado

Solución: limitar booleanas a zonas específicas.


1213. HtmlDialog re-renderiza toda la ventana al actualizar inputs numéricos

Solución: patch only changed nodes.


1214. Exportar DXF falla si un layer contiene caracteres japoneses no soportados

Solución: normalizar nombre de capa a ASCII.


1215. Importar OBJ con normales invertidas mezcla front/back faces

Solución: análisis de normal promedio y reverse selectivo.


1216. Undo de escalado deja objetos flotando 0.1–0.3 mm fuera de posición

Solución: recalcular transform final tras undo.


1217. HtmlDialog pierde focus() en inputs si el sistema operativo activa “ventanas en mosaico”

Solución: reenfocar en el evento onresize.


1218. Exportar STL usa coordenadas locales cuando debería usar globales

Solución: transformar mesh a coordenadas world.


1219. Importar DWG con unidades imperiales interpreta mal los arcos pequeños

Solución: convertir todos los radios a mm internos.


1220. Booleanas union generan caras duplicadas en sólidos con relieve superficial

Solución: remover duplicados post-operación.


1221. HtmlDialog no captura el primer click después de estar oculto detrás de otra ventana

Solución: bring_to_front + evento “mousedown dummy”.


1222. Exportar PNG se ve más oscuro porque SketchUp usa gamma diferente

Solución: post-procesar gamma +20%.


1223. Importar SKP con layers invisibles hace que pick_helper ignore ciertas entidades

Solución: activar layers temporalmente para la lectura.


1224. Booleanas restan demasiado si el sólido de corte no es completamente manifold

1225. HtmlDialog ignora inputs radio cuando se usan IDs duplicados

1226. Exportar DXF genera líneas fuera de orden cuando hay polilíneas complejas

1227. Importar OBJ con UV maps corruptos produce materiales “parchados”

1228. Undo de operaciones grandes se hace extremadamente lento (>3s)

1229. HtmlDialog parpadea cuando se alternan temas claros/oscuro del sistema

1230. Exportar STL ignora la selección si se exportan desde un HtmlDialog

1231. Importar DWG multiplica entidades cuando hay bloques referenciados múltiples veces
