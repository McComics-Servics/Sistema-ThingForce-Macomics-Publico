# Compendio de errores SketchUp McComics 801-900

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

801. Piezas quedan “aplastadas” porque la escala aplicada contiene un eje negativo no detectado

Solución: validar scale.x > 0 && scale.y > 0 && scale.z > 0.


802. HtmlDialog pierde el foco de los inputs cuando el usuario mueve la ventana del modelo

Solución: reenfocar input en onmousemove temporal.


803. Exportar despiece falla si el usuario tiene carpetas sincronizadas por OneDrive en esa ruta

Solución: guardar primero local → luego mover.


804. Componentes con demasiadas instancias producen retardos al llamar a definition.instances

Solución: cache temporal por operación.


805. Al girar el mueble en eje Z, la puerta se abre en sentido contrario

Causa: dirección del eje invertida.
Solución: recalcular vector “frente”.


806. Model.active_entities retorna Geometry de escenas ocultas

Solución: filtrar por visible? + layer.visible?.


807. HtmlDialog muestra bordes blancos cuando se usa en modo oscuro de Windows

Solución: CSS con colores basados en prefers-color-scheme.


808. Piezas creadas colapsan porque las aristas se unen en un solo punto por tolerancia muy baja

Solución: crear a escala ×10 → luego reducir.


809. Al exportar imágenes, el watermark del usuario interfiere con las dimensiones finales

Solución: desactivar watermark temporalmente.


810. El motor booleano falla cuando dos piezas comparten exactamente la misma cara

Solución: desplazar 0.1 mm una de las geometrías.


811. HtmlDialog pierde estilos si el usuario cambia el tamaño del texto del sistema operativo

Solución: usar unidades relativas (rem / em).


812. Piezas extremadamente largas (más de 10 m) provocan overflow en cálculos internos

Solución: segmentar cálculos en tramos.


813. El cálculo de normales falla cuando la pieza es perfectamente cuadrada

Solución: elegir normal basada en origen de la definición.


814. Cuando el usuario activa el modo de sección (Section Plane), las mediciones se distorsionan

Solución: ignorar caras cortadas por secciones.


815. Exportar STL causa que las curvas se triangulen en exceso y generen ruido

Solución: fijar suavizado previo.


816. HtmlDialog no acepta arrastrar archivos PDF como input

Solución: habilitar drag-and-drop con JS personalizado.


817. Tool se cancela automáticamente si el usuario usa el scroll con demasiada velocidad

Solución: limitar onMouseWheel.


818. Piezas con bordes redondeados no son consideradas “solids”

Solución: reconstruir loops internos antes de evaluar.


819. Al copiar/pegar piezas, Washington cambia el GUID del componente y se pierde metadata

Solución: persistir metadata en instancia antes del paste.


820. HtmlDialog imprime mal si se intenta usar window.print()

Solución: exportar HTML comprimido a imagen.


821. SketchUp falla al leer rutas UNC (\servidor\carpeta\archivo)

Solución: convertir a path local temporal.


822. El pick_helper ignora entidades con materiales transparentes

Solución: activar opción view.pick_transparent.


823. Copiar un mueble completo que contiene sub-muebles rompe referencias internas

Solución: reindexar UUIDs después del clone.


824. HTML deja de responder si un objeto JSON tiene profundidad mayor a 10 niveles

Solución: normalizar JSON con flatten.


825. Al mezclar escalado + rotación, el bounding box se invierte

Solución: recalcular con transform.normalized.


826. Exportar JPEG produce ruido si el modelo tiene sombras dinámicas activadas

Solución: desactivar sombras temporalmente.


827. Undo causa que piezas regresen a una ubicación vieja en modelos pesados

Solución: dividir operaciones en sub-operaciones manejables.


828. HtmlDialog ignora botones cuando un overlay semi transparente queda activo

Solución: forzar pointer-events:auto en overlay.


829. La cámara rota automáticamente cuando se crean piezas muy lejos del origen

Solución: limitar creación a 0–100 m.


830. Texturas personalizadas se ven pixeladas al exportar PNG

Solución: render 2×, luego downscale.


831. Ciertos archivos de texto no se pueden leer por estar en UTF-16

Solución: detectar encoding automáticamente.


832. Renderización de bordes dobles causa líneas fantasma en el modelo

Solución: eliminar edges duplicados por tolerancia.


833. HtmlDialog ejecuta scripts de forma lenta por variables globales excesivas

Solución: modularizar JS y encapsular.


834. El cálculo del punto medio falla si las piezas son de grosor distinto

Solución: promedio ponderado por eje dominante.


835. Al escribir atributos con hashes vacíos, SketchUp ignora diccionarios completos

Solución: insertar siempre al menos una key.


836. Piezas copiadas desde grupos rotados heredan rotación incorrecta al pegarlas

Solución: resetar transform a identidad.


837. HtmlDialog produce “flickering” cuando se actualizan valores en intervalos de 10ms

Solución: limitar actualizaciones a 30 FPS.


838. El motor de colisión detecta choques falsos cuando los paneles están inclinados

Solución: evaluar colisión rectangular, no bounding rotado.


839. Undo de texturas no revierte la orientación UV

Solución: guardar UVs previas en atributos.


840. Componentes descargados desde Warehouse contienen coordenadas negativas gigantes

841. HtmlDialog no carga fuentes locales si están en carpeta con acentos

842. Exportar video desde Scenes genera tiempos incorrectos

843. Las operaciones booleanas fallan si el plano de corte está a menos de 0.01 mm de una arista

844. SketchUp bloquea procesos si un archivo se abre con permisos “solo lectura”

845. HtmlDialog no puede renderizar sombras CSS en GPUs antiguas

846. Las piezas generadas pierden precisión en inclinaciones mayores a 60°

848. Los colores del catálogo se ven distintos entre Mac y Windows

849. El cálculo de volumen falla en piezas cónicas o trapezoidales
