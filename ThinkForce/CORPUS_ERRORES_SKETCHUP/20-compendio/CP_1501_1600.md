# Compendio de errores SketchUp McComics 1501-1600

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

1501. HtmlDialog no permite hacer selección múltiple con Shift si el WebView intercepta el evento

Solución: reenviar eventos Shift + Click manualmente.


1502. Exportar DXF invierte la dirección de polilíneas curvas cuando SketchUp las trianguló internamente

Solución: reconstruir curva desde sus vértices.


1503. Importar SKP de versiones caducadas deja estilos obsoletos que cambian el color de fondo

Solución: resetear estilo a Plantilla Base McComics®.


1504. Booleanas union fallan cuando ambos sólidos tienen caras completamente idénticas en área y orientación

Solución: introducir micro-offset antes del merge.


1505. HtmlDialog “pierde” input cuando el usuario usa teclados virtuales en pantallas táctiles

Solución: escuchar input + compositionend.


1506. Exportar STL hace que piezas redondas se vean octagonales por baja resolución de triángulos

Solución: aumentar segmentos virtuales antes de triangular.


1507. Importar OBJ con múltiples materiales provoca que las piezas aparezcan sin textura

Solución: asignar primer material válido por defecto.


1508. Undo borra atributos personalizados cuando estaban asociados a ComponentDefinition

Solución: mover atributos a instancias, no a definiciones.


1509. HtmlDialog colapsa layout si el CSS usa vh en contenedores dentro de iframes internos

Solución: usar min-height en vez de vh.


1510. Exportar PNG a baja resolución ignora líneas finas (<1 px)

Solución: render a resolución mayor y reducir después.


1511. Importar SKP con sombras dinámicas activadas cambia iluminación del modelo actual

Solución: restaurar shadow_info al terminar importación.


1512. Booleanas subtract fallan cuando los sólidos se solapan muy profundamente

Solución: dividir sólido de corte en capas.


1513. HtmlDialog no responde cuando el navegador interno activa modo “safe browsing”

Solución: deshabilitar features de bloqueo por JS.


1514. Exportar DXF crea vertices duplicados si la polilínea tiene segmentos de longitud cero

Solución: eliminar segmentos degenerados.


1515. Importar OBJ crea triangulación múltiple innecesaria en superficies suaves

Solución: simplificar malla.


1516. Booleanas intersect no detectan intersección cuando los sólidos están muy lejos del origen

Solución: recentrar operación cerca de (0,0,0).


1517. HtmlDialog pierde textos cuando la fuente del sistema cambia a una no compatible

Solución: usar fuentes embebidas.


1518. Exportar STL rompe geometría si la pieza contiene caras concavas con ángulos extremos

Solución: subdividir concavidades.


1519. Importar DWG mezcla direcciones de arco (CW/CCW) en polilíneas

Solución: corregir la dirección antes del import.


1520. Booleanas union deforman sólidos si las normales vienen inconsistentes del archivo fuente

Solución: recalcular normales globales antes de unir.


1521. HtmlDialog pierde elementos interactivos si un contenedor usa display:inline-flex

Solución: usar display:flex.


1522. Exportar PNG produce imágenes estiradas si el FrameBuffer interno cambia tamaño rápidamente

Solución: bloquear resize durante el render.


1523. Importar SKP con curvas Bézier las convierte en segmentos incorrectamente

Solución: convertir Bézier a polilínea con tolerancia fina.


1524. Booleanas subtract dejan secciones huecas cuando el sólido de corte tiene caras invertidas

Solución: invertir caras del sólido de corte.


1525. HtmlDialog falla si se activa el modo “Transparencia para ventanas” de Windows

Solución: forzar fondo sólido.


1526. Exportar DXF rompe líneas cerradas si SketchUp no detecta el cierre exacto

Solución: forzar cierre matemático de polilínea.


1527. Importar OBJ con materiales multi-layer provoca UV mezclado

Solución: reducir materiales a 1 mapa por cara.


1528. Booleanas intersect dejan triángulos invisibles si ambos sólidos tienen triangulación desigual

Solución: retesselar ambos sólidos previamente.


1529. HtmlDialog hace rendering incorrecto de SVG si contienen filtros <feGaussianBlur>

Solución: eliminar filtros o rasterizar SVG.


1530. Exportar STL duplica caras cuando un smoothing group incluye vértices no conectados

Solución: separar smoothing groups.


1531. Importar DWG incluye polilíneas 3D que SketchUp interpreta como edges flotantes

Solución: proyectar Z=0 antes del procesamiento.


1532. Booleanas union generan geometrías gigantes por acumulación de flotantes

Solución: redondear transformaciones previo al merge.


1533. HtmlDialog bloquea teclado si un input está dentro de un div con pointer-events:none

Solución: quitar pointer-events del contenedor.


1534. Exportar PNG pierde saturación si hay fog (niebla) activada

Solución: desactivar fog temporalmente.


1535. Importar SKP inserta componentes fuera del área visible cuando tienen coordenadas enormes

Solución: reposicionar a zona visible después de insertar.


1536. Booleanas subtract no detectan caras internas que están a 0.00005 mm de distancia

Solución: forzar separación mínima antes de operar.


1537. HtmlDialog ignora scroll en contenedores con borde redondeado excesivo

Solución: mover scroll al contenedor padre.


1538. Exportar DXF mezcla tipos de línea cuando hay niveles de jerarquía múltiples

Solución: aplanar jerarquía antes de export.


1539. Importar OBJ crea “triángulos colgados” que afectan el volumen final

Solución: eliminar triángulos sin conexión.


1540. Booleanas intersect dan error cuando el sólido tiene un hueco interno minúsculo

1541. HtmlDialog no renderiza iconos <img> si el path tiene caracteres UTF-16

Solución: usar rutas ASCII o base64.


1542. Exportar STL produce malla volteada si el sólido fue espejado múltiples veces

Solución: reconstruir transform con determinante positivo.


1543. Importar DWG causa que las cotas se conviertan en líneas sin texto

1544. Booleanas union producen huecos internos cuando los sólidos comparten aristas mínimas

1545. HtmlDialog bloquea el input cuando se usan sombras CSS en contenedores profundos

1546. Exportar PNG produce líneas diagonales invisibles por el filtro anti-alias

1547. Importar SKP inserta entidades con “hidden=true” sin avisar, confundiendo al usuario

1548. Booleanas subtract borran demasiado si el sólido tiene grosor 0.0001 mm

1549. HtmlDialog pierde temporalmente eventos cuando el Firewall bloquea WebView interno

1550. Exportar DXF ignora polilíneas con vértices casi duplicados dentro del margen de tolerancia

1551. HtmlDialog no permite escribir números si el sistema opera con coma decimal y el input está configurado en US-format
