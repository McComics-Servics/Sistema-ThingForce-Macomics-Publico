# Compendio de errores SketchUp McComics 1401-1500

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

1401. HtmlDialog no recibe eventos wheel cuando el usuario usa un mouse vertical ergonómico

Solución: escuchar también DOMMouseScroll y scroll.


1402. Exportar DXF genera líneas abiertas cuando provienen de curvas muy suaves

Solución: cerrar polilínea antes de exportar.


1403. Importar SKP con grupos que contienen geometría aislada produce bounding box inflado

Solución: filtrar geometría “zombie” dentro del grupo.


1404. Booleanas fallan cuando los sólidos comparten una cara completa sin tolerancia

Solución: micro-offset previo de 0.1 mm.


1405. HtmlDialog ignora eventos táctiles si el sistema tiene un “modo de accesibilidad táctil” activado

Solución: manejar touchstart/touchend manualmente.


1406. Exportar STL produce duplicación de normales cuando el sólido contiene submallas internas

Solución: eliminar submallas antes de triangular.


1407. Importar OBJ con coordenadas de textura fuera del rango [0,1] distorsiona materiales

Solución: normalizar coordenadas UV.


1408. Undo deja malla colapsada cuando se realizan subdivisiones automáticas

Solución: realizar subdivisiones dentro de operación agrupada.


1409. HtmlDialog parpadea si el CSS incluye box-shadow con valores muy grandes

Solución: usar sombras más pequeñas o internas.


1410. Exportar PNG pierde resolución cuando el viewport interno de SketchUp está minimizado

Solución: forzar re-render antes de exportar.


1411. Importar SKP desde versiones de Linux trae texturas no compatibles con Windows

Solución: convertir a PNG estándar.


1412. Booleanas intersect ignoran pequeños volúmenes internos

Solución: subdividir volumen interno antes.


1413. HtmlDialog no detecta “input” cuando el teclado del usuario envía keycodes extendidos

Solución: escuchar keyup y change también.


1414. Exportar DXF invierte la dirección de flechas en anotaciones

Solución: recrear flechas como polilíneas.


1415. Importar OBJ con coordenadas en double precision (>64-bit) causa overflow

Solución: convertir a float estándar.


1416. Booleanas fallan cuando el sólido tiene secciones parcialmente ocultas

Solución: activar temporalmente hidden_geometry.


1417. HtmlDialog “salta” el scroll si hay demasiadas imágenes cargadas de golpe

Solución: lazy loading de imágenes.


1418. Exportar STL une piezas que están muy cerca aunque no estén conectadas

Solución: separar ligeramente piezas antes.


1419. Importar DWG con tipos de línea “custom dash” crea líneas invisibles

Solución: mapear tipo de línea a continuo.


1420. Booleanas subtract fallan si el sólido de corte contiene microaristas colapsadas

Solución: limpiar aristas antes.


1421. HtmlDialog pierde estilos cuando se usan demasiados <style> internos

Solución: consolidar estilos en un solo bloque.


1422. Exportar PNG añade ruido si la GPU trabaja en modo de ahorro

Solución: forzar render sin aceleración.


1423. Importar SKP que contiene Dynamic Components “con sliders” rompe los atributos personalizados McComics

Solución: renombrar diccionarios conflictivos.


1424. Booleanas union dejan “triángulos fantasmas” cuando los sólidos son muy delgados

Solución: engrosar sólido virtualmente para operar.


1425. HtmlDialog pierde el foco si el usuario usa modo “ventanas siempre encima”

Solución: reactivar focus con timer.


1426. Exportar DXF convierte splines en bloques no editables

Solución: convertir spline a polilínea editable.


1427. Importar OBJ provoca duplicación de vértices si el archivo contiene índice negativo

Solución: corregir índices negativos.


1428. Booleanas intersect crean pequeñas aristas sueltas cuando los sólidos no son manifold

Solución: reparar manifold.


1429. HtmlDialog no responde si está contenido dentro de otro diálogo modal (MessageBox)

Solución: evitar modales nativos mientras HTML está activo.


1430. Exportar STL produce geometría invertida si la pieza tiene transform local muy compleja

Solución: bake transform antes de export.


1431. Importar DWG que contiene bloques con varias referencias causa duplicaciones internas

Solución: fusionar bloques por nombre.


1432. Booleanas subtract dejan huecos internos cuando hay geometría duplicada en la definición

Solución: eliminar duplicados antes de operar.


1433. HtmlDialog se alenta cuando se usan más de 500 elementos DOM visibles simultáneamente

Solución: paginar elementos.


1434. Exportar PNG sufre color-shift cuando se imprime en monitores wide-gamut

Solución: convertir a sRGB.


1435. Importar SKP con componentes escalados varias veces produce transformaciones erróneas

Solución: consolidar transformaciones.


1436. Booleanas union no detectan intersección si la tolerancia del modelo es demasiado estricta

Solución: aumentar tolerancia temporalmente.


1437. HtmlDialog ignora eventos “click” cuando hay un elemento transparente superpuesto sin darse cuenta

Solución: inspeccionar overlay y removerlo.


1438. Exportar STL pierde piezas pequeñas (<0.5 mm³) porque SketchUp las trata como ruido

Solución: escalar piezas pequeñas temporalmente.


1439. Importar DWG con Z-values desordenados crea geometría explorable pero incorrecta

Solución: reestablecer Z con snap.


1440. Booleanas intersect borran partes del sólido cuando hay caras casi colineales

Solución: corregir ángulo de caras previo.


1441. HtmlDialog pierde las animaciones CSS en modo de compatibilidad de Windows

Solución: fallback CSS sin animaciones.


1442. Exportar DXF ordena vértices alfabéticamente en vez de por posición

Solución: ordenar vértices antes del export.


1443. Importar OBJ produce texturas volteadas verticalmente

Solución: invertir eje V de UV.


1444. Booleanas subtract rompen aristas en piezas con curvatura variable

Solución: subdividir curvatura antes.


1445. HtmlDialog parpadea si se combinan filtros CSS + transformaciones simultáneamente

Solución: usar solo transformaciones o solo efectos.


1446. Exportar PNG pierde nitidez en monitores retina

Solución: multiplicar resolución por devicePixelRatio.


1447. Importar DWG con polilíneas 2D/3D mezcladas provoca cortes inesperados al extruir

Solución: convertir todas a 2D.


1448. Booleanas union dejan micro-sólidos internos cuando se unen mallas muy densas

Solución: limpiar sólidos internos.


1449. HtmlDialog pierde inputs si el contenedor tiene overflow:hidden y height dinámico

Solución: mover scroll a wrapper.


1450. Exportar STL falla si una pieza tiene “shared vertices” mal conectados

Solución: reparar conexión entre vértices adyacentes.


1451. HtmlDialog no permite hacer scroll lateral cuando el sistema operativo fuerza “scroll vertical only”

Solución: implementar scroll horizontal manual en JS.


1452. Exportar DXF elimina líneas si comparten el mismo punto inicial pero distinto final

Solución: separar nodos y reindexarlos antes del export.


1453. Importar SKP con estilos simplificados oculta bordes necesarios para el cálculo de piezas

Solución: restablecer estilo técnico antes de procesar.


1454. Booleanas union fallan cuando la geometría contiene vértices demasiado precisos (>12 decimales)

Solución: redondear coordenadas antes de operar.


1455. HtmlDialog pierde los valores del slider cuando el navegador interno procesa un “wheel” rápido

Solución: bloquear wheel mientras se arrastra slider.


1456. Exportar STL genera superficies ruidosas si la pieza tiene materiales con bump map

Solución: ignorar bump maps durante triangulación.


1457. Importar OBJ con materiales compartidos entre grupos causa desalineo de UV

Solución: copiar material por instancias cuando sea necesario.


1458. Undo rompe referencias de caras si se usó “smooth edges” recientemente

Solución: restaurar suavizado tras undo.


1459. HtmlDialog colapsa columnas si el CSS usa grid-template-columns: auto auto sin min-width

1460. Exportar PNG salta frames cuando se hace captura durante una animación

Solución: pausar animación antes del render.


1461. Importar SKP con caras curvas crea pseudo-curvas que desalinean maderas

1462. Booleanas subtract crean geometría “negativa” cuando la pieza contiene concavidades sin cerrar

Solución: sellar concavidades virtualmente.


1463. HtmlDialog ignora input cuando el usuario escribe demasiado rápido en teclados mecánicos

Solución: capturar eventos keyup además de input.


1464. Exportar DXF mezcla unidades si el modelo tiene capas configuradas en pulgadas

Solución: convertir todo a mm antes del export.


1465. Importar OBJ con vértices aislados genera puntos sueltos que afectan bounding

1466. Booleanas intersect no funcionan en sólidos que tienen caras trianguladas de forma irregular

1467. HtmlDialog produce saltos al hacer scroll si el CSS usa scroll-snap

1468. Exportar STL ignora cortes booleanos parciales y exporta la pieza original

1469. Importar DWG rompe coordenadas si el archivo tiene origen geoespacial

1475. HtmlDialog ignora valores numéricos si están formateados con separador de miles del usuario

1477. Importar OBJ con smoothing groups incorrectos causa sombras duras en UV planas
