# Compendio de errores SketchUp McComics 1801-1900

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

1801. HtmlDialog ignora :hover en elementos cuando el GPU entra en modo ahorro extremo

Solución: mover estilos críticos a clases activas con JS.


1802. Exportar DXF corta polilíneas cuando la densidad de vértices supera el umbral interno de SketchUp (≈10k)

Solución: simplificar polilíneas antes del export.


1803. Importar SKP rompe vistas cuando el archivo contiene “Scenes transition time = 0”

Solución: restaurar escenas a transición normal.


1804. Booleanas union fallan cuando el sólido contiene un mini-sólido embebido sin volumen real

Solución: eliminar micro-sólidos (volumen < 0.01 mm³).


1805. HtmlDialog no acepta Tab entre inputs si el sistema fuerza navegación por accesibilidad

Solución: setear tabindex manualmente en todos los controles.


1806. Exportar STL genera archivos con vértices repetidos cuando las caras están alineadas perfectamente en un eje

Solución: fusionar vértices colineales.


1807. Importar OBJ pierde geometría cuando hay vértices que referencian múltiples UVs distintos

Solución: duplicar vértices por UV.


1808. Undo no restaura correctamente materiales si estaban aplicados por “pintar el grupo por fuera”

Solución: guardar snapshot de materiales por definición.


1809. HtmlDialog se vuelve lento si hay más de 50 selects con listas grandes (>200 items)

Solución: usar listas virtuales o filtros incrementales.


1810. Exportar PNG genera píxeles brillantes si el estilo usa perfil de color “washed out”

Solución: calibrar color antes del render.


1811. Importar SKP con sombras inclinadas trae configuraciones heredadas que cambian la nitidez de sombras del proyecto

Solución: resetear shadow_info a valores McComics®.


1812. Booleanas subtract fallan cuando la pieza que resta tiene malla extremadamente fina en las puntas

Solución: reforzar puntas o extruir 0.5 mm antes.


1813. HtmlDialog bloquea el scroll si se usa position:sticky en contenedores internos

Solución: usar position:fixed o relative.


1814. Exportar DXF mezcla orden de vértices cuando la curva incluye pequeñas oscilaciones numéricas

Solución: ordenar vértices por distancia incremental.


1815. Importar OBJ interpreta normales invertidas si el archivo fue exportado con “Flip Z” activo

Solución: detectar y corregir ejes automáticamente.


1816. Booleanas intersect no detectan intersección cuando las caras están separadas por 0.00001 mm

Solución: establecer tolerancia custom.


1817. HtmlDialog no muestra imágenes cuando se usa CSS object-fit: cover combinado con bordes redondeados

Solución: mover imágenes a contenedores con clip-path neutral.


1818. Exportar STL crea triángulos con vértices fuera de orden, causando “twisted faces”

Solución: reordenar vértices clockwise.


1819. Importar DWG pierde polilíneas si el archivo usa formato DXF extendido R2007

Solución: convertir DWG a formato clásico antes de importar.


1820. Booleanas union producen microbordes cuando las piezas se tocan sólo por una arista mínima

Solución: ampliar contacto 0.1 mm.


1821. HtmlDialog hace flicker cuando se usa CSS basado en calc() en layouts complejos

Solución: pre-calcular tamaños con JS.


1822. Exportar PNG duplica sombras cuando el estilo activa “Edges by Axis”

Solución: desactivar edge coloring antes de exportar.


1823. Importar SKP provoca que algunos componentes aparezcan sin textura si el material original era procedural

Solución: convertir procedural → raster.


1824. Booleanas subtract generan sólidos huecos cuando las caras internas del cutter tienen diferente winding

Solución: homogeneizar winding antes.


1825. HtmlDialog no ejecuta scripts cuando se usa srcdoc en iframes internos

Solución: cargar scripts como archivos externos.


1826. Exportar DXF almacena textos como entidades multiline cuando deberían ser single-line

Solución: manejar formato single-line manualmente.


1827. Importar OBJ pierde materiales cuando el .mtl está en ruta relativa incorrecta

Solución: buscar .mtl mediante ruta absoluta del OBJ.


1828. Booleanas intersect fallan cuando ambos sólidos tienen partes “coplanares” exactas sin espesor

Solución: introducir pequeño desplazamiento.


1829. HtmlDialog se desconfigura si se usa vh en un monitor ultrapanorámico 34"

Solución: usar min-height basado en px o %.


1830. Exportar STL agrupa componentes simétricos en un solo mesh si comparten Definition

Solución: duplicar Definition antes de triangular.


1831. Importar DWG coloca polilíneas fuera de escala si el archivo contiene escalas anotativas mezcladas

Solución: detectar factor anotativo y normalizar.


1832. Booleanas union generan vértices duplicados cuando las aristas están demasiado juntas

1833. HtmlDialog se queda sin memoria cuando carga imágenes base64 gigantes en una sola asignación

1834. Exportar PNG pierde líneas técnicas si el estilo usa “Style Builder” personalizado

1835. Importar SKP agrega capas invisibles si la plantilla original tenía estilos antiguos

Solución: purgar capas no usadas y resetear estilo.


1836. Booleanas subtract fallan cuando el sólido objetivo tiene caras demasiado grandes sin subdivisión

1837. HtmlDialog no re-renderiza correctamente tablas grandes tras borrar filas

1838. Exportar STL produce mallas mal cerradas cuando la pieza tiene superficies tipo “patchwork”

1839. Importar DWG ignora líneas extremadamente cortas (<0.5 mm)

1840. Booleanas intersect devuelven sólidos con huecos internos si los dos modelos tienen diferencias mínimas de altura

1842. Exportar DXF genera entidades repetidas si el plugin usa loops recursivos para recolectar edges

1843. Importar OBJ coloca la geometría en coordenadas negativas si el archivo define su origen en el borde final del modelo

1844. Booleanas union disminuyen la calidad del modelo cuando el sólido tiene superficies con demasiadas subdivisiones

1845. HtmlDialog no detecta drag sobre sliders si el CSS tiene un transition aplicado al ancho

1846. Exportar STL cambia la orientación de la pieza en Z cuando las transformaciones locales tienen determinante negativo

1847. Importar DWG pierde algunos textos cuando están escritos como “MText” en formato antiguo
