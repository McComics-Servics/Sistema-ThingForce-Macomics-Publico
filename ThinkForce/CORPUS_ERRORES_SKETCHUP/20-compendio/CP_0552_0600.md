# Compendio de errores SketchUp McComics 552-600

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

552. El escalado produce distorsión porque el componente contiene elementos bloqueados internamente

Causa:
Child entities con locked=true.

Solución:
Desbloquear temporalmente → escalar → volver a bloquear.


553. Al exportar DXF, algunas piezas desaparecen porque están en “hidden geometry”

Solución:
Forzar visibilidad antes de exportar:
model.start_operation(FORCE_VISIBILITY).


554. Intersecciones booleanas fallan en piezas con caras subdivididas por triangulación

Causa:
SketchUp genera diagonales invisibles.

Solución:
Limpiar loops internos antes del boolean.


555. UI se vuelve lenta si el HtmlDialog contiene más de 2,000 nodos DOM

Causa:
CEF es muy lento con DOM grande.

Solución:
Usar paginación o virtualización de lista.


556. Timer de autoguardado sobrescribe archivos de mueble mientras usuario edita

Causa:
No validar estado activo del usuario.

Solución:
Abortar autosave si hay tool activa.


557. Transformación de un componente con escala negativa produce normals invertidas sin aviso

Síntoma:
Frentes quedan al revés.

Solución:
Detectar escala negativa y reorientar normals.


558. Error al convertir unidades cuando el usuario tiene el sistema configurado en pulgadas fraccionarias

Causa:
"1 3/8" no parsea correctamente.

Solución:
Implementar parser propio para fracciones.


559. SketchUp ignora el redraw de la UI si se ejecutan operaciones largas sin UI.start_timer

Solución:
Usar timers para yield UI.


560. Exportar PDF desde Plugin duplica el tamaño al imprimir

Causa:
Zoom del view no restablecido.

Solución:
view.zoom_extents antes del export.


561. El modelo queda “bloqueado” cuando un observer lanza excepción

Causa:
Observers no permiten fallos.

Solución:
Capturar todos los errores dentro de observer.


562. Agrupar piezas por error dentro de componente roto (no tiene entities)

Causa:
ComponentDefinition sin instancias.

Solución:
Crear instancia temporal antes.


563. Colores del catálogo no aplican porque el material ya existe en el modelo

Solución:
Clonar materiales con sufijo.


564. HtmlDialog produce error “undefined function postMessage” al abrir demasiado rápido

Causa:
Ruby envía ejecuta scripts antes de cargar DOM.

Solución:
Agregar DOMContentLoaded + retry.


565. Exportar imágenes produce sombras erráticas porque el Sol está activado

Solución:
Desactivar sombras durante export.


566. Algunos valores numéricos llegan como BigDecimal en versiones viejas de Ruby

Solución:
Convertir .to_f.


567. Crash silencioso al extruir caras con loop interno corrompido

Solución:
Validar face.loops.count > 0.


568. Exportación de BOM incluye piezas escondidas involuntariamente

Solución:
Filtrar hidden y soft entities.


569. Cálculo de bounding box de instancias anidadas falla por error de profundidad

Solución:
Recorrer instancias recursivamente.


570. Grips interactivos no funcionan en modo “Parallel Projection”

Causa:
Raycasts cambian comportamiento.

Solución:
Usar view.screen_coords.


571. HTML se rompe en pantallas ultra wide (21:9)

Solución:
Aplicar media queries específicas para > 2560px.


572. El usuario mueve una pieza mientras un timer está creando otra

Causa:
Acceso simultáneo a entidades.

Solución:
Bloquear operación con mutex interno.


573. Cargar imágenes con transparencia produce bordes negros

Solución:
Reconvertir PNG en alpha premultiplicado.


574. Crash al manipular un grupo “solamente lectura” importado desde Warehouse

Solución:
Crear copia editable.


575. Iconos del toolbar no cargan si están en carpeta con espacios Unicode

Solución:
Normalizar path a ASCII seguro.


576. Al agrupar por eje, el plugin calcula el eje basándose en bounding box en vez de dimensiones reales

Causa:
Bounding incluye biseles, guías, edges sueltos.

Solución:
Medir thickness real por vector normal.


577. Las operaciones tardan más de lo normal si hay demasiados materiales duplicados

Solución:
Eliminar duplicados antes de correr cálculos.


578. MoveTool produce saltos al interactuar con Tool McComics®

Causa:
OnMouseMove filtrado incorrectamente.

Solución:
Validar tool activa antes de reaccionar.


579. El texto en HtmlDialog se ve borroso en Mac Retina

Solución:
Usar CSS -webkit-font-smoothing: antialiased.


580. Componentes dinámicos alteran transformaciones sin aviso

Causa:
DC script ejecuta al cambiar atributos.

Solución:
Doble validación antes de mover pieza.


581. El plugin no se inicia correctamente si un archivo JS interno no carga

Causa:
Ruta relativa mal construida.

Solución:
Usar ruta absoluta interna:
File.join(**dir**, "ui/js/app.js").


582. Undo no revierte cambios en materiales

Causa:
Materiales son objetos globales.

Solución:
Crear materiales nuevos para cada operación.


583. La rotación de piezas pierde precisión cuando se hace con valores pequeños (<1°)

Solución:
Uso de cuaterniones o normalizar ángulos.


584. HtmlDialog tarda en abrir por CSS demasiado pesado

Solución:
Minificar CSS o inline critical CSS.


585. Crash en Mac al usar rutas con mayúsculas donde el sistema usa minúsculas

Solución:
Normalizar a downcase las rutas.


586. Exportar despiece genera duplicados cuando hay componentes espejo

Causa:
Reflection matrices.
Solución:
Detectar transformaciones con escala negativa.


587. Tool se queda “atascada” porque falta implementar onCancel

Solución:
Agregar onCancel(view).


588. Pérdida de metadata al copiar componentes entre modelos

Solución:
Mover metadata con .attribute_dictionaries.


589. Al abrir HtmlDialog grande, SketchUp congela por falta de throttling en JS

Solución:
Usar requestAnimationFrame.


590. Escalar un componente dentro de un grupo con escala diferente produce doble escala

Solución:
Convertir escala del grupo a 1 antes de aplicar.


591. Al cargar script muy largo, Ruby lanza “stack level too deep”

Causa:
Recursión accidental.
Solución:
Convertir recursión en iteración.


592. Tool McComics® no detecta clic porque la cámara está invertida

Causa:
Up vector cambiado.
Solución:
Restablecer cámara estándar.


593. HtmlDialog no puede enviar objetos complejos (clases) a Ruby

Solución:
Serializar como JSON plano.


594. SketchUp ignora UI.messagebox durante operaciones largas

Solución:
Romper operación en trozos con timers.


595. Caras pequeñas (<1mm²) desaparecen al exportar a STL

Causa:
Triangulación.
Solución:
Fusionar caras pequeñas.


596. Botón de ayuda abre archivo local bloqueado por Windows SmartScreen

Solución:
Firmar archivo o usar protocolo https.


597. Al borrar un componente, la UI sigue mostrando opciones antiguas

Solución:
Enviar mensaje JS → Ruby → JS para refresh.


598. Campos numéricos en HtmlDialog se limpian cuando el usuario usa coma

Solución:
Reemplazar comas automáticamente en JS.


599. Mover una pieza provoca que otras “salten” porque están vinculadas a mismo definition

Solución:
Clonar definición ante cambios estructurales.


600. Operación de corte (subtract) revienta cuando el plano de corte coincide con una arista

Causa:
Solid engine falla en coplanar.
Solución:
Mover plano 0.1 mm antes de cortar.
