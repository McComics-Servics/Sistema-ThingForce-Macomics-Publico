# Compendio de errores SketchUp McComics 2001-2100

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

2001. HtmlDialog no procesa doble clic en inputs porque el WebView interpreta el segundo clic como selección de texto

Solución: detectar doble clic por timestamps y bloquear selección en ese input puntual.


2002. Exportar DXF genera microsegundos en el orden de entidades cuando el modelo tiene miles de grupos anidados

Solución: exportar por niveles jerárquicos ordenados.


2003. Importar SKP con materiales escalados múltiple veces da como resultado texturas estiradas en exceso

Solución: resetear UV y reescalar material al 100%.


2004. Booleanas union fallan cuando el sólido contiene clusters de vértices de tamaño submicroscópico

Solución: eliminar clústeres de vértices con tolerancia.


2005. HtmlDialog ignora el estado “checked” en radiobuttons cuando el formulario se reconstruye con innerHTML

Solución: restaurar “checked” desde JavaScript manualmente.


2006. Exportar STL une piezas separadas si comparten exactamente los mismos vértices tras transformaciones

Solución: duplicar vertices por identidad de pieza.


2007. Importar OBJ interpreta mal la escala cuando el archivo usa unidades arbitrarias declaradas sólo en comentarios

Solución: leer metadatos manuales y aplicar escala correcta.


2008. Undo rompe atributos avanzados de definiciones si se editan dentro del mismo frame

Solución: agrupar edición en una operación start/commit.


2009. HtmlDialog oculta botones si el contenedor usa position:sticky encima de position:fixed

Solución: reorganizar el stacking context.


2010. Exportar PNG produce “moiré patterns” en superficies con texturas repetitivas

Solución: aumentar sampleo de texturas.


2011. Importar SKP desde versiones 2013–2015 hace que algunos componentes se importen como instancias vacías

Solución: regenerar definición desde geometría interna.


2012. Booleanas subtract fallan cuando el cutter se compone de aristas con radios negativos (errores de import)

Solución: corregir radios negativos.


2013. HtmlDialog bloquea detección de teclado si el CSS aplica transform: translateZ(0) a inputs

Solución: evitar transformaciones 3D en inputs.


2014. Exportar DXF mezcla textos y curvas cuando ambos comparten la misma coordenada base

Solución: separar por capas o desplazar mínimamente textos.


2015. Importar OBJ pierde caras si la triangulación interna incluye caras con más de 4 puntos (n-gons)

Solución: dividir n-gons en triángulos antes de importar.


2016. Booleanas intersect generan caras negativas cuando el sólido tiene caras coincidentes en diagonal

Solución: rotar ligeramente antes de intersectar.


2017. HtmlDialog no muestra scrollbars si el usuario usa “scrollbars hidden” a nivel sistema

Solución: implementar scroll custom con JS.


2018. Exportar STL genera triángulos duplicados cuando el mapeo UV tiene costuras profundas

Solución: suavizar seam previo a exportar.


2019. Importar DWG hace que líneas en capas apagadas aparezcan igual si están asociadas a bloques activos

Solución: filtrar visibilidad real del bloque.


2020. Booleanas union rompen superficies cilíndricas cuando los cilindros no comparten la misma normal

Solución: recalcular la normal principal de ambos.


2021. HtmlDialog pierde tooltip cuando el contenedor usa overflow:clip

Solución: usar overlay independiente para tooltips.


2022. Exportar PNG de ángulos extremos crea sombras con banding

Solución: aplicar dithering de sombra.


2023. Importar SKP trae texturas corrompidas cuando fueron guardadas en HEIC o formatos Apple

Solución: convertir primero a PNG.


2024. Booleanas subtract pierden precisión cuando el cutter está escalado más de 10×

Solución: reescalar cutter a 1× interna.


2025. HtmlDialog distorsiona iconos cuando se mezclan imágenes retina con no-retina

Solución: usar conjuntos de iconos escalados proporcionalmente.


2026. Exportar DXF produce líneas sin dirección cuando los vectores son paralelos al eje Z

Solución: forzar proyección al plano XY.


2027. Importar OBJ genera pérdida total de malla cuando el archivo contiene índices con offset erróneo

Solución: reindexar secuencialmente.


2028. Booleanas intersect dejan bordes dentados cuando las dos piezas usan diferente resolución de subdivisión

Solución: unificar subdivisión de ambos sólidos.


2029. HtmlDialog no renderiza sombras CSS si el WebView usa aceleración compartida

Solución: deshabilitar GPU para ese HtmlDialog.


2030. Exportar STL mezcla varias piezas si comparten la misma Definition y se expanden en memoria

Solución: duplicar Definition previa.


2031. Importar DWG interpreta mal cotas cuando el texto está fuera del “dimension line”

Solución: realinear cotas al centro geométrico.


2032. Booleanas union dejan gaps cuando una cara tiene una curvatura extremadamente sutil

Solución: suavizar curva previa.


2033. HtmlDialog muestra fuentes muy pequeñas si el usuario tiene un “Text Scaling” personalizado en OS

Solución: medir devicePixelRatio y ajustar automáticamente.


2034. Exportar PNG elimina gradientes cuando se combinan perfiles de color no estándar

Solución: convertir a sRGB antes de exportar.


2035. Importar SKP borra escenas ocultas que en realidad contenían datos de cámaras útiles

Solución: preservar escenas ocultas marcadas.


2036. Booleanas subtract producen geometría corrupta cuando un sólido tiene caras que se cruzan a sí mismas

Solución: reparar self-intersections previas.


2037. HtmlDialog deja zonas clicables bloqueadas si un div invisible quedó con z-index alto

Solución: limpiar overlays huérfanos al iniciar UI.


2038. Exportar STL interpreta bordes afilados como discontinuidades y crea doble malla

Solución: fusionar normales en aristas continuas.


2039. Importar DWG rompe líneas curvas cuando el archivo usa SPLINE con anchura variable

Solución: convertir SPLINE a curvas uniformes.


2040. Booleanas union hacen perder pequeños detalles como chaflanes mínimos

Solución: detectar detalles minúsculos y protegerlos antes.


2041. HtmlDialog no muestra emojis porque el motor CEF no tiene fuentes unicode extendidas

Solución: cargar fuente emoji embebida.


2042. Exportar DXF invierte coordenadas Y si el modelo trabajó en sistema Y-up (poco común)

Solución: mapear al estándar SketchUp Z-up.


2043. Importar OBJ pierde partes de la geometría cuando la definición “usemtl” aparece en interlineados incorrectos

Solución: limpiar archivo antes de cargarlo.


2044. Booleanas subtract generan errores cuando el cutter toca sólo un borde y no penetra realmente

Solución: validar penetración mínima.


2045. HtmlDialog pierde animaciones cuando demasiados elementos tienen transición simultánea

Solución: reducir número de transiciones.


2046. Exportar STL falla si el modelo tiene superficies sin área definible (faces formadas solo por 2 vértices)

Solución: limpiar geometría degenerada.


2047. Importar DWG produce distorsiones cuando el archivo trae “Ejes auxiliares” girados por otras apps CAD

Solución: resetear UCS y transformar a WCS.


2048. Booleanas union fallan cuando ambos sólidos son extremadamente delgados (<0.2 mm)

Solución: engrosar sólidos virtualmente.


2049. HtmlDialog oculta elementos cuando se usa position:relative en un contenedor cuyo padre tiene overflow:hidden

Solución: mover elementos interactivos a capas superiores.


2050. Exportar DXF causa desplazamiento del origen si el usuario movió el eje del modelo pero no lo restauró

Solución: recalcular export basado en ejes globales originales.


2051. HtmlDialog no conserva el foco cuando se navega con teclas de flecha dentro de listas largas

Solución: usar preventDefault() y manejo manual de selección.


2052. Exportar DXF pierde curvas cerradas si están formadas por 3 segmentos mínimos

Solución: detectar cierre circular y fusionar antes del export.


2053. Importar SKP desde Warehouse genera thumbnails corruptos que ralentizan el Outliner

Solución: purgar thumbnails tras la importación.


2054. Booleanas union fallan si el sólido contiene micro-separaciones internas entre caras que parecen unidas

Solución: soldar bordes internos antes de operar.


2055. HtmlDialog aplica fonts incorrectas cuando el sistema tiene override forzado de tipografías

Solución: usar fuentes embebidas en base64.


2056. Exportar STL vuelve convexas superficies que deberían ser cóncavas debido a triangulación inapropiada

Solución: retesselar con algoritmo de concavidad.


2057. Importar OBJ destruye superficies grandes si contienen múltiples materiales mezclados en una sola cara

Solución: dividir cara por material antes de usarla.


2058. Undo no restaura correctamente objetos con “Lock Entity” activado

Solución: desactivar lock temporalmente al entrar en start_operation.


2059. HtmlDialog no detecta keyup en Mac cuando el usuario usa teclados mecánicos con criticidad alta

Solución: escuchar input + change como fallback.


2060. Exportar PNG produce aliasing en bordes inclinados con estilos técnicos

Solución: activar anti-aliasing alto temporal.


2061. Importar SKP con escenas animadas activa transiciones que se ejecutan en medio de tus herramientas

Solución: desactivar animaciones de escena durante uso del plugin.


2062. Booleanas subtract fallan si el cutter tiene una parte interna hueca que coincide con la cara contraria

Solución: rellenar hueco interno antes.


2063. HtmlDialog mezcla scroll horizontal y vertical cuando los contenedores no especifican dirección

Solución: añadir overflow-y:auto explícito.


2064. Exportar DXF rota textos 90° si en SketchUp estaban en modo 2D screen-aligned

Solución: reposicionar textos al plano XY antes.


2065. Importar OBJ borra elementos si el archivo usa “material by face” sin agrupar definiciones

Solución: crear Definition por grupo de materiales.


2066. Booleanas intersect generan huecos cuando hay aristas con curvatura mínima en piezas con muchísimos segmentos

Solución: simplificar previamente.


2067. HtmlDialog bloquea botones si un elemento flotante con position:absolute está mal posicionado por -1 px

Solución: ajustar z-index y bounding.


2068. Exportar STL altera el modelo si se exporta durante un Undo/Redo activo

Solución: esperar a que el modelo esté estable antes del export.


2069. Importar DWG crea objetos de tamaño cero si el archivo contiene “proxy entities” corruptas

Solución: ignorar proxies o sanear DWG antes.


2070. Booleanas union fallan cuando un sólido tiene un borde con curvatura muy reducida y ángulos negativos

Solución: suavizar borde.


2071. HtmlDialog no detecta drag en pantallas táctiles antiguas (Android 7–8)

Solución: usar eventos touchstart/move/end.


2072. Exportar PNG pierde profundidad de sombras cuando el sol está casi perpendicular al plano

Solución: ajustar la posición del sol para export.


2073. Importar SKP con varios estilos activa “shadow on faces” que oscurece la visualización de melamina

Solución: desactivar esa opción al iniciar herramientas.


2074. Booleanas subtract dejan picos microscópicos cuando dos caras intersectan a 179.999°

Solución: planarizar ambas caras.


2075. HtmlDialog rompe el layout si se usa justify-content: space-evenly en contenedores críticos

Solución: preferir space-between o center.


2076. Exportar DXF ignora polilíneas 3D si su altura Z varía menos de 0.01 mm

Solución: proyectar 3D a XY.


2077. Importar OBJ reparte materiales incorrectamente cuando el .mtl contiene rutas relativas rotas

Solución: reconstruir rutas a partir del path del OBJ.


2078. Booleanas intersect generan geometría “fantasma” si uno de los sólidos incluye caras no visibles pero existentes

Solución: borrar caras ocultas.


2079. HtmlDialog usa demasiado CPU cuando se aplican sombras en texto (text-shadow)

Solución: remover sombras en textos dinámicos.


2080. Exportar STL produce duplicación de triangulación cuando la pieza tiene caras extremadamente estrechas

Solución: eliminar caras con aspect ratio extremo.


2081. Importar DWG borra atributos de texto porque SketchUp no soporta multiline text en 3D space

Solución: dividir textos multiline en líneas individuales.


2082. Booleanas union deforman caras planas cuando el sólido tiene una malla con vértices “colapsados”

Solución: soldar todos los vértices vecinos.


2083. HtmlDialog queda en blanco si la ventana se inicializa con dimensiones menores a 100×100 px

Solución: iniciar con tamaño mínimo recomendado.


2084. Exportar DXF produce errores con arcos que provienen de extrusiones en SketchUp

Solución: convertir a arcos reales antes del export.


2085. Importar SKP de archivos muy pesados hace que el Outliner se recalcule durante operaciones del plugin

Solución: desactivar Outliner temporalmente.


2086. Booleanas subtract eliminan piezas completas cuando su bounding coincide exactamente con el del mueble

Solución: desplazar la pieza 0.01 mm.


2087. HtmlDialog se congela cuando se usan varias animaciones en hover dentro de listas largas

Solución: limitar animaciones a elementos seleccionados.


2088. Exportar STL ignora superficies si todos los triángulos combinan normales opuestas

Solución: corregir winding antes de triangular.


2089. Importar DWG genera polígonos rotos cuando el archivo tiene splines 3D convertidas a líneas demasiado cortas

Solución: fusionar líneas.


2090. Booleanas union no preservan el material original de cada pieza

Solución: reasignar materiales después del merge.


2091. HtmlDialog desconfigura botones si se usa display:grid sin filas definidas

Solución: definir filas/columnas explícitas.


2092. Exportar PNG falla cuando el plugin cambia el FOV justo antes del render

Solución: bloquear FOV para export.


2093. Importar SKP trae escalas erróneas porque el archivo tenía “Scale Definition on Load” activo

2094. Booleanas subtract dejan líneas sobrantes si el sólido tiene bordes no suavizados

Solución: suavizar bordes antes de restar.


2095. HtmlDialog mueve la UI completa si un elemento usa resize:both sin querer

Solución: deshabilitar resize en todos los contenedores.


2096. Exportar STL coloca triángulos duplicados si la Definition fue “flipped” varias veces

2097. Importar DWG crea mallas irreales si el archivo contenía “solids” de AutoCAD convertidos mal

2098. Booleanas union dejan caras invisibles cuando el sólido original tenía agujeros semi-ocultos

Solución: rellenar agujeros previamente.


2099. HtmlDialog no dispara eventos en botones si el CSS aplica opacity:0.99 (bug raro de CEF)

2100. Exportar DXF no respeta la orientación del eje rojo si el usuario rotó el eje pero no lo guardó

Solución: normalizar ejes para export sin depender de axes movidos.
