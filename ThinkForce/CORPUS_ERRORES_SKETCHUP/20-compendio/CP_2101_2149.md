# Compendio de errores SketchUp McComics 2101-2149

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

2101. HtmlDialog ignora el evento wheel cuando el usuario usa un mouse con modo “smooth scrolling” activado

Solución: escuchar DOMMouseScroll o pointermove como fallback.


2102. Exportar DXF duplica entidades cuando la geometría viene de componentes con “hidden geometry” visible

Solución: filtrar hidden edges antes del export.


2103. Importar SKP desde archivos de terceros puede traer materiales con nombres idénticos pero hash distinto

Solución: fusionar materiales con nombre duplicado.


2104. Booleanas union fallan cuando un sólido incluye microtriángulos creados por importaciones incorrectas

Solución: eliminar cualquier triángulo con área <0.0001.


2105. HtmlDialog no permite que los <input type="file"> funcionen cuando se carga HTML desde string

Solución: cargar UI desde archivo físico o activar permisos de fileinput.


2106. Exportar STL genera superficies distorsionadas si el modelo fue escalado varias veces en distintos ejes

Solución: bakear transformaciones antes de triangular.


2107. Importar OBJ ignora subconjuntos cuando el archivo incluye grupos con nombres vacíos

Solución: asignar nombre automático basado en índice.


2108. Undo no restaura copias múltiples creadas en un mismo frame

Solución: agrupar clonados dentro de una sola operación undo.


2109. HtmlDialog oculta el cursor cuando el componente usa cursor:inherit desde un contenedor invisible

Solución: definir cursor:auto explícitamente en la UI.


2110. Exportar PNG muestra sombras poco definidas cuando el tamaño del canvas es mayor a 10,000 px

Solución: render por bloques (tiling).


2111. Importar SKP borra geometrias con materiales “no asignables” como placeholders de otros software

Solución: reemplazar esos materiales antes de importarlos.


2112. Booleanas subtract fallan cuando el cutter contiene caras superpuestas con normals opuestas

Solución: eliminar duplicados antes de aplicar.


2113. HtmlDialog detiene animaciones si el usuario activa “Modo ahorro de energía” en Windows

Solución: degradar animaciones a instantáneo.


2114. Exportar DXF invierte texto si el estilo tiene dirección RTL (right-to-left)

Solución: forzar modo LTR para export.


2115. Importar OBJ pierde caras con UV extendidos más allá de 1.0

Solución: normalizar UV a rango válido.


2116. Booleanas intersect generan geometría extremadamente fina cuando los sólidos están casi paralelos

Solución: rotar ligeramente uno de ellos.


2117. HtmlDialog bloquea <textarea> si un div transparente está flotando 1 px encima

Solución: limpiar overlays invisibles.


2118. Exportar STL encoge la pieza si el modelo tiene un escalado negativo que invierte ejes

Solución: reorientar matriz local antes.


2119. Importar DWG crea líneas invisibles si el archivo traía color “BYBLOCK” pero sin block válido

Solución: asignar color por defecto.


2120. Booleanas union pierden precisión en cilindros achatados al importar desde herramientas paramétricas externas

Solución: reconstruir cilindros en SketchUp.


2121. HtmlDialog no reacciona a botones si la UI usa filter:blur() en contenedores padres

Solución: evitar filtros en capas superiores.


2122. Exportar DXF convierte arcos perfectos en curvas poligonales por límite interno de SketchUp

Solución: regenerar arcos antes de exportar.


2123. Importar SKP genera rotaciones extrañas si el archivo contiene ejes internos movidos por plugins de terceros

Solución: restaurar ejes de cada Definition.


2124. Booleanas subtract borran parte de un mueble cuando el cutter toca sólo un borde sin penetrar

Solución: validar profundidad de penetración.


2125. HtmlDialog deja de mostrar íconos si se carga demasiado rápido antes que el motor CEF inicialice

Solución: forzar retardo de 50–100 ms antes de mostrar UI.


2126. Exportar STL pierde vértices adyacentes cuando la superficie está dividida por aristas muy pequeñas

Solución: fusionar vértices.


2127. Importar DWG duplica entidades cuando los bloques tienen referencias circulares

Solución: romper la referencia circular al importar.


2128. Booleanas union generan huecos en piezas de melamina cuando los cantos fueron modelados con caras delgadas

Solución: engrosar cantos antes del merge.


2129. HtmlDialog no permite enfoque correcto si usas autofocus en múltiples inputs

Solución: dejar un solo autofocus global.


2130. Exportar PNG ignora edges cuando la cámara está muy cerca del modelo

Solución: aumentar near plane.


2131. Importar SKP produce pérdida de color si el material usa “alpha masked” incompatible con SU

Solución: convertir alpha a PNG estándar.


2132. Booleanas subtract dejan piezas fantasma si el sólido tiene caras cerradas pero no manifold

Solución: reparar manifold con unificador de mallas.


2133. HtmlDialog bloquea menú contextual en Mac si se redefine el handler nativo por error

Solución: restaurar comportamiento default.


2134. Exportar DXF genera polilíneas invertidas si el usuario invierte los ejes del modelo manualmente

Solución: reorientar polilíneas a XY.


2135. Importar OBJ desplaza la geometría a una posición inaccesible si los bounding iniciales son enormes

Solución: normalizar bounding al centro.


2136. Booleanas intersect colapsan cuando la pieza tiene varias cavidades internas cerradas

Solución: dividir el sólido por cavidades y operar por secciones.


2137. HtmlDialog ralentiza el teclado si se usa un listener “keyup” demasiado pesado

Solución: throttle a 30–60ms.


2138. Exportar STL mezcla piezas si todas comparten vertices globales (rarísimo pero ocurre con scripts)

Solución: separar mallas por pieza antes.


2139. Importar DWG ignora líneas punteadas porque el patrón “LTYPE” no existe en SketchUp

Solución: convertir patrones a tipo sólido.


2140. Booleanas union producen geometría rota cuando se cruzan múltiples curvas complejas en 3D

Solución: simplificar curvas.


2141. HtmlDialog cambia colores de botones cuando el OS tiene “high saturation mode” activo

Solución: usar colores fijos no dependientes del OS.


2142. Exportar PNG pierde transparencias con fondo blanco forzado

Solución: setear fondo transparente antes del render.


2143. Importar SKP trae componentes “congelados” si tenían ejes ocultos asignados por otro plugin

Solución: restaurar ejes internos.


2144. Booleanas subtract pierden pequeños taladros si están demasiado cerca del borde

Solución: desplazar taladros 0.01 mm.


2145. HtmlDialog no suelta scroll cuando el CSS usa touch-action:none

Solución: remover touch-action del contenedor principal.


2146. Exportar STL genera vértices en diagonal cuando el modelo usa escalado no uniforme

Solución: aplicar matriz de corrección uniforme.


2147. Importar DWG inserta objetos muy lejos del origen cuando el archivo se creó con coordenadas topográficas absolutas

Solución: recentrar modelo antes de trabajar.


2148. Booleanas union modifican bounding box final, afectando despieces automatizados

Solución: recalcular bounding post-operación.


2149. HtmlDialog hace que inputs numéricos no acepten punto decimal cuando el OS usa coma como separador

Solución: convertir SQL-like: coma→punto antes de parsear.

\*2150. Exportar DXF elimina entidades duplicadas incluso si eran necesarias para representar grosor

Solución: duplicar líneas críticas como “doble trazo” antes de export.
