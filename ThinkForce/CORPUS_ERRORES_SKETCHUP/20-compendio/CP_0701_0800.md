# Compendio de errores SketchUp McComics 701-800

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

701. HtmlDialog no recibe mensajes porque Ruby responde antes de que el DOM exista

Síntoma: postMessage no llega a JS.
Solución: Esperar DOMContentLoaded y reenviar.


702. El sistema de favoritos se rompe si el usuario borra la carpeta McComics desde el explorador

Solución: Validar y recrear estructura completa al cargar.


703. Exportar despiece en modelos con “Soft Edges” activado produce fallos en longitudes

Causa: Soft edges oculta bordes reales.
Solución: Forzar visibilidad antes de medir.


704. Undo falla si el plugin inicia un start_operation sin descripción

Solución: Siempre incluir nombre claro.


705. El usuario crea piezas a partir de caras con textura proyectada y las UVs se distorsionan

Solución: Reasignar UVs manualmente usando position_material.


706. Al aplicar una textura repetida a una pieza escalada, la textura aparece deformada

Solución: Recalcular UV según escala absoluta.


707. HtmlDialog se congela si se envían arrays de más de 2000 elementos

Solución: Fragmentar datos en paquetes.


708. Cerrar SketchUp mientras un timer sigue activo produce crash silencioso

Solución: Registrar at_exit y cancelar timers.


709. Duplicar un mueble con Ctrl+Mover conserva referencias internas no deseadas

Solución: Resetear metadata al clonar.


710. El plugin falla si el usuario activa la herramienta mientras el HTML está cargando

Solución: Bloquear herramientas hasta que JS confirme “READY”.


711. Exportar DXF con piezas curvas convierte arcos en demasiados segmentos

Solución: Definir tolerancia óptima según tamaño.


712. HtmlDialog pierde CSS cuando el usuario cambia al modo High Contrast de Windows

Solución: CSS fallback ligero.


713. En modelos muy grandes, model.selection.clear tarda demasiado

Solución: Limpieza asíncrona con timer.


714. Tools personalizadas no reciben onLButtonDoubleClick

Solución: Implementar doble click manual midiendo tiempo entre clics.


715. Al editar componentes anidados, los cambios afectan a submuebles no deseados

Solución: Hacer make_unique_recursive.


716. Rutas absolutas provocan fallos cuando el usuario mueve la carpeta del plugin

Solución: Usar **dir** para todo.


717. La ruta de logs contiene caracteres no válidos en Windows

Solución: normalizar con solo A–Z y 0–9.


718. Exportar JPG en blanco porque la cámara estaba mirando al infinito

Solución: validar direction vector != cero.


719. Rotar una pieza 90° rompe la orientación del sistema de bisagras

Solución: recalcular normal + vector derecha.


720. HtmlDialog produce “blanco” si el archivo HTML pesa más de 800 KB

Solución: minificar HTML y JS.


721. Timers pierden referencia a variables locales y ejecutan con estado incompleto

Solución: usar variables de módulo o closure estable.


722. La interfaz muestra valores de milímetros en centímetros por mal redondeo

Solución: formatear siempre con 3 decimales.


723. SketchUp bloquea la exportación de texturas muy grandes (10K×10K)

Solución: redimensionar a 4096 máximo.


724. Observer de cámara se dispara 100 veces por segundo y bloquea UI

Solución: throttling con última llamada cada 0.1 s.


725. El usuario escribe comillas dobles en nombres de muebles y rompe JSON

Solución: sanitizar con escape.


726. Al cargar un catálogo de piezas, los nombres duplicados sobrescriben items

Solución: generar hash único por ID.


727. Un mueble con más de 300 piezas produce “operation nesting too deep”

Solución: dividir operaciones en bloques.


728. El motor booleano falla si los sólidos no son “watertight”

Solución: reparar geometría con edge.merge.


729. HtmlDialog pierde scroll cuando se re-renderiza un div grande

Solución: guardar y restaurar scrollTop.


730. Al exportar imágenes, el fondo queda negro si el estilo tiene background personalizado

Solución: cambiar temporalmente a background estándar.


731. Selección múltiple ignora piezas que tienen “hidden geometry visible” desactivado

Solución: forzar visibilidad temporal.


732. Al pegar componentes desde otro modelo, se pierden atributos porque están en Definition

Solución: copiar attributes a cada instancia.


733. Línea guía creada por el plugin no se borra porque pertenece a otro contexto

Solución: registrar parent antes de crearla.


734. El usuario cambia de escena mientras la tool está activa y se pierde el estado

Solución: manejar evento onViewChanged.


735. A veces SketchUp toma el eje local del componente como global

Solución: corregir con transform.inverse.


736. Existen caras casi invisibles que rompen operaciones booleanas

Solución: eliminar caras < 0.0001 m².


737. Entities.multiply no funciona con instancias de componentes vacíos

Solución: crear geometría placeholder.


738. Paneles con cantos biselados crean bounding box inflado

Solución: calcular bounding real extrayendo edges principales.


739. Cerrar HtmlDialog con X en lugar de botón causa estado inconsistente

Solución: capturar evento onClosed y limpiar estado.


740. La herramienta no detecta clic si el cursor está sobre una guía (guide point)

Solución: filtrar guide points en pick_helper.


741. El usuario trafica una pieza con MoveTool mientras tu tool lee selección

Solución: bloquear lectura hasta mouse up.


742. Exportar BOM produce error si una pieza tiene nombre vacío

Solución: asignar nombre por defecto “Pieza\_#{id}”.


743. El plugin calcula grosor incorrecto cuando la pieza está rotada 90° en eje Y

Solución: determinar normal dominante antes de medir.


744. HtmlDialog produce parpadeo cuando SketchUp redimensiona su ventana

Solución: CSS con transition: none;.


745. Componentes importados desde Revit vienen con miles de aristas innecesarias

Solución: limpiar con edge.erase! si edge.soft? && edge.smooth?.


746. Importar materiales con nombres repetidos provoca conflictos en el model

Solución: renombrar con sufijos incremental.


747. Usuarios con idioma Alemán generan errores por usar comas como decimales

Solución: convertir , → . antes de parsear.


748. Grupos que contienen imágenes (SketchUp Image) rompen transformaciones

Solución: convertir imágenes a textura/material.


749. Cerrar y abrir rápidamente el HtmlDialog crea múltiples instancias en memoria

Solución: patrón Singleton para diálogos.


750. Undo no revierte cambios en atributos dentro de herramientas activas

Solución: envolver cambios siempre dentro de start/commit_operation.


751. HtmlDialog pierde el estado cuando el usuario cambia el tamaño de la ventana de SketchUp

Solución: Guardar estado en localStorage y restaurar al cargar.


752. Un componente no responde a transformaciones porque está marcado como “glued”

Solución: instance.glued_to = nil antes de aplicar transform.


753. Deshacer borra piezas creadas dentro de un context equivocado

Solución: cerrar context antes de start_operation.


754. Cuando un mueble tiene múltiples niveles de anidación, el cálculo de ejes internos se invierte

Solución: obtener transform acumulada hasta el root.


755. HtmlDialog ignora clicks si un elemento tiene pointer-events: none heredado

Solución: revisar estilos y limpiar herencias no deseadas.


756. Al colapsar el panel de Outliner, el plugin pierde referencia al componente activo

757. Exportar imágenes con antialiasing alto produce bordes borrosos

758. El cálculo de vetas falla cuando la textura no está alineada al eje local

759. Componentes con instancias vacías generan errores de conteo en el despiece

760. HtmlDialog no puede cargar imágenes SVG en Windows 8

762. Si el usuario desactiva “Display Edges”, los pick_helper fallan

765. HtmlDialog produce scroll infinito por error en padding de CSS

766. Texturas de catálogo fallan cuando el usuario trabaja sin conexión
