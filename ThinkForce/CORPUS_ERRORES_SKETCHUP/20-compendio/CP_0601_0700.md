# Compendio de errores SketchUp McComics 601-700

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

601. HtmlDialog carga pero el JS no ejecuta porque el archivo está en caché antigua

Causa: Cache agresiva de CEF.
Solución: Agregar ?v=#{Time.now.to_i} a los assets.


602. Pérdida de precisión al convertir medidas entre mm ↔ pulgadas fraccionarias

Causa: Redondeos múltiples.
Solución: Convertir siempre a flotantes en mm internos y luego formatear.


603. Crash al intentar duplicar una Definition que contiene DC scripts

Causa: SketchUp bloquea clones de definiciones dinámicas.
Solución: Usar make_unique y limpiar ATTS_DC.


604. Observer de materiales activo genera eventos infinitos

Causa: Modificación dentro del callback.
Solución: Usar una bandera @inside_material_change.


605. Model.active_path regresa nil durante operaciones complejas

Causa: Llamar dentro de un timer.
Solución: Verificar model.active_path&.any?.


606. Extrusiones fallan cuando el eje Z está invertido por cámara isométrica modificada

Causa: Raycast devuelve normal incorrecta.
Solución: Normalizar vector en world space.


607. HtmlDialog no envía mensajes a Ruby porque el canal se cerró prematuramente

Causa: GC elimina el dialog si no guardas referencia global.
Solución: Guardar en variable del módulo @@dialog.


608. Muebles creados dentro de grupos con escala ≠ 1 producen dimensiones incorrectas

Solución: Obtener group.transformation.scaling y corregir.


609. Undo rompe el estado si había timers pendientes de ejecutar

Solución: Cancelar timers antes de iniciar operación.


610. Al renombrar definiciones, referencias de materiales se pierden

Causa: materiales ligados a antiguos definition names.
Solución: Guardar metadata con UUID, no con nombre.


611. Grupos importados desde Warehouse vienen con axis rotado 179.999°

Solución: Redondear ángulos pequeños a 0.


612. JS ejecuta doble evento “change” si el input tiene oninput + onchange

Solución: usar solo uno y desactivar el otro.


613. El usuario hace “Ctrl+Z” mientras HtmlDialog está enviando datos

Causa: estado inconsistente.
Solución: bloquear UI hasta finalizar operación de Ruby.


614. Model.start_operation falla si otra extensión está ejecutando operación activa

Causa: multi-extensión conflict.
Solución: intentar con commit_operation antes.


615. Face.extrude crea geometría invertida si la cara es muy pequeña

Solución: aumentar escala temporal x10 → extruir → restaurar.


616. Tools no capturan eventos de teclado si HtmlDialog tiene foco

Solución: usar JS para enviar eventos manuales a Ruby.


617. Instancias espejo producen colisiones fantasma en tu motor de colisiones

Solución: detectar transformaciones con determinante negativo.


618. Materiales con alpha producen caras negras por pre-multiplicación

Solución: recrear textura con alpha corregida.


619. HTML input type=“number” en Chrome no acepta valores > 99999 en algunas culturas

Solución: type="text" + validación manual.


620. Al aplicar transform consecutivo, se pierde el origen del mueble

Solución: concatenar transforms y normalizar matriz.


621. Temporizador de autosave remueve focus del usuario

Solución: guardar/leer estado de foco.


622. Archivos JS no cargan en Mac por nombres con mayúsculas diferentes

Solución: forzar downcase en rutas.


623. Cuando el usuario mueve el modelo completo, las referencias al root se pierden

Solución: recalcular root desde entities parent.


624. Grips 3D no se posicionan bien cuando la cámara está en modo Corrección de Perspectiva

Solución: calcular desde view.camera.eye correctamente.


625. Context menu (clic derecho) afecta tools personalizados

Causa: menú bloquea flujo de eventos.
Solución: redefinir onCancel.


626. Memory leak por listas estáticas usadas como cache global

Solución: limpiar caché cada recarga del plugin.


627. Exportar imágenes desde la cámara genera bordes negros si el FOV está muy bajo

Solución: ajustar fov mínimo 20°.


628. Grupos parametrizados se duplican al deshacer si el atributo “created_by” está mal usado

Solución: usar uuid por instancia.


629. HtmlDialog crea scrollbar aunque la UI quepa

Solución: overflow:hidden + min-height dinámico.


630. Undo deja entidades zombis en carpetas ocultas de componentes

Solución: limpiar definition.entities antes de borrar.


631. Obtener selection demasiado rápido retorna una selección desactualizada

Causa: SketchUp no refresca instantáneo.
Solución: UI.start_timer(0.1).


632. Transformaciones largas producen acumulación de flotantes en matrices

Solución: redondear matriz a 6 decimales.


633. HtmlDialog bloquea la rueda del mouse en Mac

Solución: agregar listener a wheel con preventDefault:false.


634. Archivo de logs no rota y crece indefinidamente

Solución: rotación por tamaño (max 5 MB).


635. Aplicar materiales a grupos vacíos produce error silencioso

Solución: validar entities.any?.


636. Modelo se vuelve lento si hay demasiados ConstructionPoints ocultos

Solución: borrarlos después de usar.


637. Importar imágenes grandes genera scroll automático que rompe layout

Solución: redimensionar a máximo 512px.


638. Llamar a set_status_text dentro de loops produce flickering

Solución: throttling cada 200 ms.


639. HtmlDialog en 4K se escala mal si el usuario tiene escalado del sistema en 150%

Solución: CSS con unidades relativas (vw, vh, rem).


640. Definiciones temporales quedan instaladas en el modelo y aumentan el tamaño del archivo

Solución: eliminar definitions no instanciadas.


641. Cuando el usuario usa un template de SketchUp, tu plugin no encuentra la estructura inicial

Causa: entidades preexistentes.
Solución: crear carpeta interna McComics.


642. Undo no revierte atributos escritos en definitions

Solución: usar instancias locales.


643. El usuario abre dos modelos a la vez y el plugin escribe defaults en el modelo equivocado

Solución: usar model.guid para aislar configuración.


644. HTML congela si se usa alert() dentro del WebView

Solución: reemplazar por diálogo custom.


645. SketchUp no permite cargar archivos .svg como iconos

Solución: convertirlos a PNG base64 32×32.


646. Transformación de piezas falla si el grupo tiene parent con rotación no uniforme

Solución: reconstruir matriz local → world space → new local.


647. Filtros de selección no funcionan si el usuario tiene activado el modo “Editar componente por defecto”

Solución: detectar con model.active_path.


648. Importación DXF ignora capas ocultas y rompe el modelado posterior

Solución: forzar visibilidad antes del procesamiento.


649. Exportar despiece en modelos muy cargados produce timeouts en HtmlDialog

Solución: procesar despiece por lotes con timers.


650. Cargar presets desde JSON produce error si hay comentarios // en el archivo

Solución: limpiar comentarios antes de parsear.


651. Cargar archivos de configuración antes de que SketchUp termine de inicializar

Síntoma: El plugin parece no recordar configuraciones.
Solución: Usar UI.start_timer(0.1) antes de leer archivos externos.


652. HtmlDialog falla si el archivo contiene BOM UTF-8

653. Al cambiar el estilo de cámara, los grips 3D se desplazan

654. Mover piezas dentro de un componente produce desplazamientos acumulativos

656. HtmlDialog deja de responder si el usuario abre otro diálogo encima

657. Exportar JPG produce colores apagados por perfil de color

658. Crash al extruir una cara que pertenece a un componente con escalado no uniforme

659. Model.entities.add_group produce grupos invisibles si el estilo de SketchUp oculta edges

660. Cuando un temporizador crea entidades en medio de un undo, SketchUp pierde consistencia

661. Piezas exactas (sin holgura) provocan solapamiento visual y quiebre del motor booleano
