# Compendio de errores SketchUp McComics 1901-2000

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

1901. HtmlDialog ignora el click en botones si el CSS aplica pointer-events:none a un contenedor ancestral sin querer

Solución: aplicar pointer-events sólo a overlays específicos.


1902. Exportar DXF pierde continuidad cuando la polilínea incluye arcos extremadamente pequeños

Solución: fusionar micro-arcos en un segmento recto.


1903. Importar SKP trae sombras incorrectas si la escena original tenía “solar north” modificado

Solución: restablecer north a la orientación estándar McComics®.


1904. Booleanas union fallan cuando un sólido tiene triángulos diminutos que SketchUp interpreta como agujeros

Solución: eliminar triángulos <0.01 mm².


1905. HtmlDialog distorsiona imágenes si el contenedor usa aspect-ratio complejo

Solución: bloquear aspect-ratio y usar width/height controlados.


1906. Exportar STL deja huecos si la triangulación tiene “fan patterns” con vértices colapsados

Solución: re-mallar usando triangulación Delaunay.


1907. Importar OBJ revienta el UV si el archivo usa “multi-index arrays” (varios sets simultáneos)

Solución: tomar solo el primer set de UV estable.


1908. Undo borra transformaciones pero no restaura el eje del componente

Solución: guardar y restaurar axis manualmente.


1909. HtmlDialog no detecta scroll cuando un div interno usa overflow:hidden por error de herencia

Solución: revisar jerarquía de contenedores y corregir overflow.


1910. Exportar PNG aparece más claro u oscuro si tu estilo usa “colorize texture”

Solución: desactivar colorize temporalmente.


1911. Importar SKP convierte algunos componentes en grupos si tienen metadata de Dynamic Component corrupta

Solución: recrear Definition manualmente.


1912. Booleanas subtract no detectan el cutter si está rotado 180.0001°

Solución: normalizar rotación a valores exactos.


1913. HtmlDialog pierde precisión numérica cuando JS redondea flotantes automáticamente

Solución: usar Number.toFixed() en cada render.


1914. Exportar DXF revienta cuando la capa incluye caracteres especiales como “Ç” o “Ñ”

Solución: transliterar nombres antes del export.


1915. Importar OBJ genera caras faltantes cuando el archivo usa materiales inconsistentes entre grupos

Solución: forzar un solo material por grupo.


1916. Booleanas intersect producen resultados vacíos cuando ambos sólidos son extremadamente delgados

Solución: engrosar temporalmente.


1917. HtmlDialog deja inputs invisibles cuando se aplica backface-visibility:hidden en el contenedor

Solución: quitar backface-visibility en layers interactivos.


1918. Exportar STL crea vértices duplicados cuando las caras tienen UV discontinuos

Solución: reempaquetar UVs antes de triangular.


1919. Importar DWG mezcla entidades si el archivo tiene capas anidadas (XRefs + Blocks)

Solución: aplanar capas en estructura lineal.


1920. Booleanas union colapsan cuando el sólido contiene una superficie con demasiados “creases” ocultos

Solución: suavizar creases antes de unir.


1921. HtmlDialog no ejecuta transiciones CSS cuando prefers-reduced-motion está activado

Solución: fallback a animaciones instantáneas.


1922. Exportar PNG hace clipping del borde exterior si el framing interno no está centrado

Solución: auto-centrar cámara según bounding.


1923. Importar SKP suelta los ejes personalizados del modelo original y los aplica al tuyo

Solución: reestablecer model.axes.


1924. Booleanas subtract dejan bordes colgando si los sólidos se tocan sólo en un microsegmento

Solución: aumentar tolerancia de colisión.


1925. HtmlDialog ignora onchange en number inputs si la rueda del mouse cambia el valor rápidamente

Solución: escuchar input + change.


1926. Exportar DXF desordena entidades si el modelo contiene geometría generada por scripts con IDs fuera de orden

Solución: reindexar entidades.


1927. Importar OBJ produce artefactos si el archivo incluye vértices referenciados por caras no trianguladas

Solución: triangulación previa.


1928. Booleanas intersect devuelven vacío cuando el volumen común es extremadamente pequeño

Solución: escalar ambos sólidos ×10 y operar.


1929. HtmlDialog se quiebra visualmente si el CSS usa flex-basis: fit-content en elementos críticos

Solución: usar bases fijas.


1930. Exportar STL genera malla desalineada cuando el componente tiene transformaciones no uniformes embebidas

Solución: bake transform de Definition.


1931. Importar DWG pierde polilíneas 3D que provienen de delineación automatizada

Solución: proyectar a plano XY antes.


1932. Booleanas union producen exceso de triángulos en zonas sin necesidad

Solución: re-mallar con tolerancia angular.


1933. HtmlDialog se cuelga si una imagen PNG grande falla en decodificar

Solución: pre-cargar imágenes en Ruby antes de abrir la UI.


1934. Exportar DXF genera errores si un bloque tiene escala negativa en un solo eje

Solución: convertir eje negativo a positivo antes.


1935. Importar OBJ duplica la geometría si el archivo contiene indexado negativo mezclado con positivo

Solución: reindexar totalmente.


1936. Booleanas subtract borran más de lo deseado cuando los sólidos se superponen en más de un 80%

Solución: dividir cutter en 2 o más partes.


1937. HtmlDialog pierde textos si el color del sistema es “alto contraste blanco-negro invertido”

Solución: forzar CSS con colores explícitos.


1938. Exportar STL produce caras “bowtie” si el modelo usa UV seams muy extendidos

Solución: suavizar seams antes de triangular.


1939. Importar DWG oculta líneas pequeñas al interpretar el color “BYLAYER” como transparente

Solución: asignar color por defecto.


1940. Booleanas intersect generan “picos” en la geometría cuando las caras se cruzan en ángulos mínimos

Solución: planarizar caras antes.


1941. HtmlDialog no ejecuta scripts en elementos que se agregan mediante innerHTML tras el primer render

Solución: re-bind de scripts dinámicos.


1942. Exportar PNG reproduce un borde negro alrededor del modelo cuando los perfiles tienen antialiasing bajo

Solución: subir AA a 4x o más.


1943. Importar SKP dispersa piezas en el aire si el archivo tenía “axes moved” aplicado a subgrupos

Solución: recalcular ejes de cada Definition.


1944. Booleanas subtract se equivocan cuando el sólido principal tiene caras superpuestas exactamente

Solución: eliminar duplicados.


1945. HtmlDialog pierde comportamiento de botones si la hoja CSS usa display:contents

Solución: evitar display:contents en contenedores interactivos.


1946. Exportar DXF produce saltos en polilíneas cuando un vértice está exactamente duplicado

Solución: purgar duplicados antes.


1947. Importar OBJ genera distorsión visual en zonas planas si el archivo contiene normales calculadas por software distinto

Solución: recalcular normales en SketchUp.


1948. Booleanas union crean pequeñas cavidades internas por diferencias mínimas de altura entre sólidos

Solución: alinear ambos sólidos al mismo plano base.


1949. HtmlDialog no procesa keyup si el focus pasa automáticamente a otro elemento por CSS animado

Solución: detener animaciones durante edición.


1950. Exportar STL produce archivo inválido si el determinante de la matriz local es cero por error de transform

Solución: regenerar matriz antes de triangular.


1951. HtmlDialog no captura Esc para cerrar la ventana si el foco está dentro de un <select> abierto

Solución: escuchar keydown global y cerrar manualmente en keyCode === 27.


1952. Exportar DXF genera polilíneas partidas cuando los vértices tienen mezcla de unidades (pulgadas y mm)

Solución: normalizar todas las coordenadas a mm antes de exportar.


1953. Importar SKP desde archivos muy viejos (SketchUp 6–7) trae caras “front/back” invertidas

Solución: detectar caras con normales hacia adentro y voltearlas automáticamente.


1954. Booleanas union fallan cuando un sólido tiene huecos internos modelados con caras back-face

Solución: obligar todas las caras back-face a orientarse hacia afuera antes de unir.


1955. HtmlDialog deja de responder si se mezclan eventos click y pointerdown sobre el mismo botón

Solución: elegir un solo tipo de evento para interacción primaria.


1956. Exportar STL produce escalado incorrecto cuando el modelo está configurado en pulgadas pero el CNC espera mm

Solución: multiplicar las coordenadas por 25.4 al generar STL.


1957. Importar OBJ rompe la suavidad de curvas si el archivo fue exportado con “Edge Split” activo

Solución: reagrupar vértices y recalcular smoothing por ángulo límite.


1958. Undo no restaura correctamente componentes anidados si se usó “Explode” dentro de una operación grande

Solución: agrupar cualquier “explode” dentro de la misma operación de undo para mantener consistencia.


1959. HtmlDialog genera barras de scroll dobles (en página y en contenedor)

Solución: dejar scroll solo en un nivel (body o contenedor principal, nunca ambos).


1960. Exportar PNG recorta texto 3D si el bounding box no se recalcula tras mover la cámara

Solución: forzar view.zoom model.entities justo antes de exportar.


1961. Importar SKP de un modelo topográfico gigantesco hace que el mueble parezca diminuto

Solución: detectar escala global y sugerir reescalar el modelo o trabajar en archivo separado.


1962. Booleanas subtract fallan cuando el cutter es un sólido con paredes de grosor 0 (cara doble sin espesor)

Solución: dar espesor mínimo al cutter (offset).


1963. HtmlDialog pierde el highlight de campos requeridos cuando el CSS redefine :invalid

Solución: crear clases propias de validación y no depender de :invalid.


1964. Exportar DXF borra líneas auxiliares de referencia que estaban en una capa oculta pero necesaria para el CNC

Solución: permitir al usuario marcar capas “forzar export” aunque estén ocultas.


1965. Importar OBJ desordena la jerarquía cuando el archivo mezcla o (object) y g (group) sin orden

Solución: definir reglas claras: o → grupos, g → subgrupos, y reconstruir a mano.


1966. Booleanas intersect generan polvo de triángulos al cruzar cilindros muy subdivididos

Solución: reducir segmentos de los cilindros antes de aplicar la intersección.


1967. HtmlDialog no deja copiar texto con Ctrl+C en algunos teclados internacionales

Solución: escuchar también keyCode alternativos y comandos del menú contextual.


1968. Exportar STL triangula mal las superficies de bisel cuando el ángulo es menor a 1°

Solución: forzar subdivisión extra en biseles antes de triangular.


1969. Importar DWG reescala todo el plano si el archivo tiene un “INSUNITS” inconsistente

Solución: leer INSUNITS y aplicar factor de escala adecuado al entrar a SketchUp.


1970. Booleanas union destruyen agujeros pasantes si el algoritmo los interpreta como ruido

Solución: marcar esos cilindros como “no eliminar” y reinsertarlos después de la unión.


1971. HtmlDialog pierde la alineación de íconos cuando se activa zoom del navegador interno sin querer (Ctrl + rueda)

Solución: deshabilitar zoom con event.preventDefault() en Ctrl+wheel.


1972. Exportar PNG satura el color de melaminas claras cuando el brillo global está alto

Solución: aplicar curva de corrección de gamma exclusiva para export.


1973. Importar SKP trae etiquetas (Tags) con nombres duplicados que confunden el filtrado del plugin

Solución: normalizar nombres de tags y fusionar duplicados.


1974. Booleanas subtract dejan micro-aristas dentro del sólido que luego causan fallos en nuevos booleanos

Solución: pasar un limpiador de geometría interna tras cada operación.


1975. HtmlDialog no permite reordenar listas arrastrables (drag & drop) si el data-transfer está bloqueado

Solución: implementar drag basado en posición de mouse en vez de API nativa de HTML5.


1976. Exportar DXF arma mal las cotas acotadas que estaban asociadas a aristas de grupos ocultos

Solución: recalcular cotas sobre geometría “real” antes de exportar.


1977. Importar OBJ crea geometría flotando muy arriba si el modelo fue creado con “ground plane” artificial desplazado

Solución: detectar altura mínima del modelo y bajar Z para que apoye en 0.


1978. Booleanas intersect devuelven geometría sin espesor visible cuando el volumen de intersección es casi plano

Solución: descartar intersecciones con grosor menor a cierto umbral, o engrosar volumen.


1979. HtmlDialog provoca destellos (flicker) en dark mode cuando se alterna theme con transiciones de fondo

Solución: evitar transition sobre background-color y hacer el cambio instantáneo.


1980. Exportar STL genera sólidos no válidos para impresión cuando hay vértices compartidos por más de 2 caras

Solución: convertir la geometría a manifold dividiendo vértices conflictivos.


1981. Importar DWG trae textos acotados que pierden unidad (mm, cm)

Solución: añadir sufijo de unidad al texto o convertirlos a cota pura en SketchUp.


1982. Booleanas union reproducen ruido en esquinas donde se cruzan más de tres sólidos

Solución: unir primero en pares y luego el resultado con el resto, no todos a la vez.


1983. HtmlDialog no guarda estados de pestañas si se recrea el DOM completamente en cada cambio

Solución: manejar el estado en JS (store) y sólo ocultar/mostrar pestañas.


1984. Exportar DXF rota el plano de trabajo si el modelo fue girado para trabajar “en vertical”

Solución: reorientar el modelo temporalmente al plano XY para la exportación.


1985. Importar SKP desde modelos BIM trae capas, escenas y estilos que ensucian el archivo de mueblería

Solución: importar en archivo vacío auxiliar y sólo copiar lo necesario al archivo de trabajo.


1986. Booleanas subtract se rompen cuando el cutter contiene caras internas no visibles pero conectadas

Solución: detectar y borrar cualquier cara totalmente interna antes de usarlo como cutter.


1987. HtmlDialog se ve borroso en monitores 125% de escala cuando no se usan unidades relativas en fuentes

Solución: trabajar con rem y em en lugar de px fijos.


1988. Exportar STL ignora detalles muy pequeños (chaflanes, redondeos) por limitación de tolerancia

Solución: definir un modo de “alta precisión” que preserve pequeñas características.


1989. Importar OBJ produce objetos con sombras raras si el archivo trae normales calculadas desde espacio OpenGL invertido

Solución: invertir normales según convención y recalcular.


1990. Booleanas intersect calculan mal el volumen cuando el sólido tiene un hueco interno en forma de “donut”

Solución: separar en dos sólidos (cuerpo + hueco) y operar por partes.


1991. HtmlDialog no deja escribir correctamente en inputs numéricos en móviles porque el teclado pone comas en lugar de puntos

Solución: interceptar input, reemplazar comas por puntos antes de parsear.


1992. Exportar DXF no incluye bloques si su visibilidad estaba controlada por “Tag” apagado

Solución: ofrecer opción “incluir geometría apagada pero etiquetada como exportable”.


1993. Importar SKP genera conflicto de nombres si tu plugin ya creó Definitions con el mismo nombre

Solución: renombrar automáticamente con prefijos EXT*, IMP*, etc.


1994. Booleanas union mezclan sólidos de distintos muebles si el usuario selecciona todo el modelo por error

Solución: limitar operaciones a grupos/estructuras marcadas como “mueble activo McComics®”.


1995. HtmlDialog se desbalancea cuando la fuente principal no está instalada y cae en una alternativa con métricas muy distintas

Solución: elegir fuentes fallback de métricas similares (ej. Roboto ↔ Noto Sans).


1996. Exportar STL genera error en algunos slicers porque no escribe “solid name” y “endsolid” de forma consistente

Solución: generar encabezado y pie estándar por cada cuerpo exportado.


1997. Importar DWG confunde ejes cuando el archivo tiene un UCS girado en 3D para cada bloque

Solución: convertir todos los UCS a WCS antes de crear geometría en SketchUp.


1998. Booleanas subtract eliminan herrajes modelados (bisagras, tornillos) porque están dentro del sólido principal

Solución: marcar herrajes con Tag/atributo especial y excluirlos de booleanas estructurales.


1999. HtmlDialog no permite fullscreen correcto en Mac si no se configura el dialog como “resizable” desde Ruby

Solución: crear HtmlDialog con resizable: true y gestionar tamaño máximo desde JS.


2000. Exportar DXF pierde el sentido de las vetas/axis porque sólo saca líneas, sin metadatos de orientación

Solución: escribir capas o bloques separados por eje o sentido de veta y usar nombres codificados (ej. EJE_X, EJE_Y).
