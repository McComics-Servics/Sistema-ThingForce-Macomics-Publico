# Compendio de errores SketchUp McComics 1701-1800

Fuente: ./ARCHIVOS ORIGINALES/ERRORES_QUE_LA IA_DEBE EVITAR_COMETER_RESUMIDO_SketchUp-McComics.md
Origen: resumen lineal denso del corpus

Uso: abrir solo el tramo necesario cuando se requiera cobertura amplia o busqueda por numero/solucion.

---

1701. HtmlDialog no detecta “dblclick” si el sistema operativo está en modo “reducción de movimiento”

Solución: simular doble clic analizando timestamps.


1702. Exportar DXF pierde polilíneas si los vértices tienen coordenadas extremadamente pequeñas (<1e-9)

Solución: redondear vértices antes de exportar.


1703. Importar SKP desde iOS inserta escenas ocultas adicionales

Solución: eliminar escenas invisibles tras importar.


1704. Booleanas union fallan cuando los sólidos tienen caras curvas con tensores distintos

Solución: normalizar curvatura.


1705. HtmlDialog no renderiza gradientes CSS complejos en GPUs integradas

Solución: usar gradientes simples o imágenes rasterizadas.


1706. Exportar STL genera líneas sueltas cuando la triangulación contiene “bowtie faces”

Solución: subdividir bowties en triángulos válidos.


1707. Importar OBJ ignora materiales cuando los nombres contienen caracteres UTF-16

Solución: normalizar nombres ASCII.


1708. Undo no restaura correctamente la orientación si se aplicó Mirror dentro de un grupo

Solución: aplicar mirror desde componente raíz.


1709. HtmlDialog pierde el estado CSS si se aplica zoom global del sistema a 175%

Solución: recalcular layout con unidades relativas.


1710. Exportar PNG crea bordes dentados cuando el FOV es demasiado estrecho (<10°)

Solución: ajustar FOV temporalmente.


1711. Importar SKP escala mal los componentes si la plantilla original usaba unidades imperiales

Solución: convertir todo a mm al importar.


1712. Booleanas subtract fallan cuando una pieza tiene caras no manifold con vértices duplicados

Solución: soldar y reparar non-manifold.


1713. HtmlDialog no muestra iconos cuando el path interno contiene espacios dobles

Solución: sanitizar path mediante encodeURI.


1714. Exportar DXF convierte líneas curvas en segmentos muy cortos que saturan el archivo

Solución: fusionar segmentos reduciendo densidad.


1715. Importar OBJ reconstruye mal UVs si están fuera del rango 0–1

Solución: clamping de UV.


1716. Booleanas intersect dan resultados vacíos cuando los sólidos están alineados perfectamente en plano XY

Solución: rotar levemente alguno.


1717. HtmlDialog bloquea inputs si un CSS usa overflow:clip en contenedores interactivos

Solución: usar overflow:auto.


1718. Exportar STL produce duplicados invisibles cuando el smoothing está roto

Solución: regenerar smoothing.


1719. Importar DWG genera errores si el archivo usa unidades mezcladas (mm y cm)

Solución: detectar unidad dominante.


1720. Booleanas union rompen vértices cuando los sólidos están parcialmente superpuestos en el eje Z

Solución: planarizar alineación previa.


1721. HtmlDialog pierde scroll si el contenedor usa min-height:100vh

Solución: reemplazar por min-height:auto.


1722. Exportar PNG mezcla sombras múltiples si el modelo tiene varias escenas activas

Solución: congelar escena actual previa.


1723. Importar SKP borra materiales que no estén usados directamente en caras (pero sí en componentes)

Solución: preservar materials por uso en definición.


1724. Booleanas subtract no detectan piezas muy delgadas (<0.5 mm)

Solución: escalar pieza temporalmente.


1725. HtmlDialog oculta elementos si el CSS tiene filter:brightness(0) por error

Solución: corregir filtros globales.


1726. Exportar DXF rompe vértices si las coordenadas exceden ±1e9

Solución: adaptar a rango seguro.


1727. Importar OBJ genera triangulación invertida por error de winding CW/CCW mezclado

Solución: recalcular winding por normal promedio.


1728. Booleanas intersect producen microcaras cuando el sólido está ligeramente inclinado (0.01°)

Solución: corregir inclinación.


1729. HtmlDialog pierde los estilos si la carga HTML tarda más de 5 segundos

Solución: aplicar “DOMContentLoaded” fallback.


1730. Exportar STL genera mesh duplicada cuando el grupo contiene instancias anidadas repetidas

Solución: aplanar instancias previas.


1731. Importar DWG ignora líneas sin color asignado (color 0)

Solución: dar color por defecto.


1732. Booleanas union fallan cuando los sólidos tienen superficies con curvatura mínima distinta

Solución: homogeneizar curvatura.


1733. HtmlDialog requiere doble clic en algunos botones cuando el contenedor usa border-radius extremo

Solución: ajustar hitbox.


1734. Exportar PNG pierde calidad en monitores 4K con scaling 300%

Solución: render a escala nativa.


1735. Importar SKP corrompe instancias cuando las definiciones tienen nombres idénticos pero IDs distintas

Solución: renombrar definiciones.


1736. Booleanas subtract borran la pieza completa si ambos sólidos tienen el mismo volumen exacto

Solución: alterar volumen mínimo.


1737. HtmlDialog no captura onChange en <select> en CEF muy antiguos

Solución: escuchar click + input.


1738. Exportar DXF fusiona polilíneas si comparten 2 vértices consecutivos

Solución: separar vértices antes del export.


1739. Importar OBJ produce tiras de triángulos invisibles si hay UV discontinuos

Solución: reconstruir malla sin UV conectados.


1740. Booleanas intersect no detectan contacto si las piezas están demasiado lejos del origen del modelo

Solución: mover operación cerca del origen.


1741. HtmlDialog ralentiza scroll cuando contiene <iframe> aunque esté oculto

Solución: eliminar iframes ocultos.


1742. Exportar STL genera mesh rota cuando el sólido tiene simetrías múltiples

Solución: recalcular simetría.


1743. Importar DWG pierde arcos si el archivo usa formato SPLINE sin parámetros válidos

Solución: convertir spline a segmentos.


1744. Booleanas union fallan si el sólido objetivo tiene múltiples shells internos no conectados

Solución: separar shells y unirlos uno por uno.


1745. HtmlDialog no muestra tooltips si el usuario tiene modo de “alto contraste” activado

Solución: crear tooltips propios en JS.


1746. Exportar PNG crea zonas quemadas si SketchUp usa exposición alta

Solución: bajar exposición antes del render.


1747. Importar SKP multiplica las instancias si el archivo tenía “placeholders” ocultos

Solución: limpiar definiciones fantasma.


1748. Booleanas subtract fallan cuando el sólido pequeño tiene volumen casi cero

Solución: reescala x10.


1749. HtmlDialog ignora botones si una animación CSS bloquea el thread visual

Solución: desactivar animación en hover.


1750. Exportar DXF elimina entidades en Z negativa si el exportador filtra por vista top

Solución: reorientar a plano XY.


1751. HtmlDialog no dispara eventos en inputs cuando el sistema fuerza teclado virtual flotante

Causa: el WebView pierde foco al abrir el teclado.
Solución: re-enfocar el input en focusin y tras resize.


1752. Exportar DXF desordena cotas cuando el texto está en un UCS distinto al WCS

Solución: transformar todas las cotas al WCS antes de exportar.


1753. Importar SKP desde Warehouse trae componentes con ejes aleatorios que rompen tu lógica de montaje

Solución: re-definir eje de cada definition al estándar McComics® al cargar.


1754. Booleanas union fallan cuando uno de los sólidos fue generado por un plugin que deja edges “soft+hidden” internos

Solución: hacer view.hidden_geometry = true y limpiar edges internos antes de unir.


1755. HtmlDialog ignora click en iconos SVG cuando tienen pointer-events:none heredado del CSS de reset

Solución: forzar pointer-events:auto en los SVG interactivos.


1756. Exportar STL genera doble capa de triángulos en piezas huecas modeladas como cascarón

Solución: eliminar caras internas o unificar shell antes de exportar.


1757. Importar OBJ con múltiples grupos anidados rompe la jerarquía de SketchUp (todo llega plano)

Solución: reconstruir jerarquía a partir de nombres de grupo.


1758. Undo revierte la geometría pero no revierte atributos de licencia o metadata del plugin

Solución: incluir escritura de atributos dentro de la misma operación de Undo.


1759. HtmlDialog se pixela cuando el usuario tiene escalado del sistema a 200% en monitores 720p

Solución: usar devicePixelRatio para ajustar tamaños de fuente y layout.


1760. Exportar PNG corta parte del mueble cuando la relación de aspecto de la ventana no coincide con la resolución pedida

Solución: calcular resolución respetando el aspect ratio de la vista.


1761. Importar SKP desde plantillas de arquitectura inserta secciones activas que ocultan tus muebles

Solución: desactivar y borrar SectionPlane no marcados como McComics®.


1762. Booleanas subtract fallan cuando el sólido de corte es una malla importada sin soldar vértices

Solución: soldar todos los vértices coincidentes antes de usar como cutter.


1763. HtmlDialog no deja escribir números negativos porque el input type="number" usa min="0" fijado por error

Solución: parametrizar min desde Ruby según el contexto del plugin.


1764. Exportar DXF suelta textos en posiciones inesperadas cuando SketchUp usa alignment “Above baseline”

Solución: recalcular punto de inserción de textos al centro geométrico.


1765. Importar OBJ genera sombras cruzadas porque el archivo trae light sources embebidos

Solución: ignorar / eliminar luces al leer el OBJ.


1766. Booleanas intersect devuelven sólidos inválidos cuando el modelo está muy lejos del origen mundial (>1 km)

Solución: mover temporalmente la selección cerca del origen, operar y regresar.


1767. HtmlDialog bloquea el scroll si hay un div full-screen transparente usado como overlay de carga

Solución: desactivar overlay o añadir pointer-events:none.


1768. Exportar STL produce un archivo enorme cuando no se purgan componentes y mallas no usadas

Solución: ejecutar model.purge_unused antes de preparar el mesh de exportación.


1769. Importar DWG trae hatch de mobiliario que se confunde visualmente con tus piezas de melamina

Solución: mover hatch a una capa “DWG_IMPORT” y apagarla por defecto.


1770. Booleanas union mezclan sólidos de distintos materiales sin preservar el material dominante

Solución: al finalizar, reasignar material según porcentaje de área por sólido original.


1771. HtmlDialog no guarda configuraciones si el localStorage está deshabilitado por políticas corporativas

Solución: hacer fallback a atributos en el modelo (AttributeDictionary McComics).


1772. Exportar DXF pierde bloques si los nombres comienzan con un número o caracteres especiales

Solución: mapear nombres a identificadores seguros (ej. B_001_PUERTA).


1773. Importar SKP con geolocalización activa rota la sombra según latitud/longitud del archivo original

Solución: resetear sun position al estándar del proyecto actual.


1774. Booleanas subtract dejan un sólido aparente correcto pero con volumen calculado en cero

Solución: verificar manifold y rehacer triangulación interna.


1775. HtmlDialog se ve lavado (colores muy claros) cuando el usuario tiene activado “Night light” fuerte en Windows

Solución: usar paleta con más contraste y menos dependencia de tonos cercanos.


1776. Exportar STL fusiona piezas de distintos layers al mismo sólido perdiendo la estructura de módulos

Solución: exportar por capas o por grupos en iteraciones separadas.


1777. Importar OBJ que fue exportado desde Blender con “Apply Transform” desactivado llega con ejes desfasados

Solución: recalcular transformaciones locales a partir de bounding box.


1778. Undo no revierte posición de cámara cuando la herramienta McComics hace zoom automático

Solución: encapsular cambios de cámara dentro de la operación con model.active_view.


1779. HtmlDialog deja de reaccionar si el hilo de Ruby ejecuta un cálculo pesado sin UI.start_timer

Solución: delegar procesos largos a timers o threads externos y mantener la UI viva.


1780. Exportar PNG muestra líneas negras en los bordes de cada cara por exceso de perfil en el estilo

Solución: temporalmente bajar Profiles a 1 o 0 antes de exportar.


1781. Importar SKP desde otro plugin de muebles trae atributos con claves genéricas ("width", "height") que chocan con las tuyas

Solución: namespacing de atributos: siempre MC_Width, MC_Height, etc.


1782. Booleanas union fallan cuando el sólido tiene una pequeña pieza interna “flotando” sin conexión

Solución: detectar y eliminar sub-sólidos flotantes antes de la operación.


1783. HtmlDialog no muestra correctamente iconos base64 largos porque superan el límite del HTML inyectado

Solución: mover sprites a archivos externos o usar versiones base64 optimizadas.


1784. Exportar DXF desordena bloques cuando se reutiliza el mismo nombre de componente en contextos distintos

Solución: renombrar definiciones con prefijo de contexto (MODULO_ALTO_PUERTA_A, etc.).


1785. Importar DWG con XRefs no resueltos deja referencias vacías que parecen huecos en el plano

Solución: advertir al usuario y convertir XRefs en geometría local o descartarlos explícitamente.


1786. Booleanas subtract fallan cuando el grosor del sólido es exactamente igual a la tolerancia del modelo

Solución: aumentar la precisión interna o engrosar 0.1 mm antes.


1787. HtmlDialog pierde el foco en campos de texto cuando se dispara un postMessage desde Ruby en cada keypress

Solución: limitar mensajes Ruby⇄JS solo a cambios confirmados (blur / enter).


1788. Exportar STL incluye geometría oculta de pruebas internas del plugin (debug solids)

Solución: marcar geometría debug con capa/atributo y excluirla explícitamente del export.


1789. Importar OBJ trae normales “hard edge” que rompen el aspecto suave de bordes melamínicos

Solución: recalcular smoothing por ángulo (<30°) y reexportar o corregir al importar.


1790. Booleanas intersect devuelven piezas extremadamente fragmentadas cuando se cruzan muchas perforaciones

Solución: agrupar perforaciones similares y operar por lotes en zonas localizadas.


1791. HtmlDialog se redibuja completo al cambiar un simple checkbox porque se usa un framework que hace full-rerender

Solución: cambiar a actualización incremental o componentes ligeros para opciones frecuentes.


1792. Exportar DXF omite líneas de detalle de canto si están en una capa cuyo nombre contiene espacios finales

Solución: limpiar nombres de capa (strip) antes de exportar.


1793. Importar SKP con estilos de “Sketchy Edges” hace perder precisión visual en las vistas técnicas para corte

Solución: forzar un estilo técnico limpio al activar cualquier herramienta McComics® de despiece.


1794. Booleanas union crean un sólido correcto pero dejan atributos component_instance incoherentes (nombre, descripción)

Solución: reasignar atributos desde una plantilla de Definition nueva al finalizar.


1795. HtmlDialog no escala correctamente cuando se arrastra desde un monitor 4K a uno HD

Solución: recalcular layout en cada screen / window change.


1796. Exportar STL utiliza ejes globales cuando lo correcto sería respetar el eje local del módulo (para CNC)

Solución: transformar la malla a coordenadas locales del componente antes de escribir STL.


1797. Importar DWG con textos anotativos (Annotative Text) cambia de tamaño al pasar a SketchUp

Solución: convertir textos anotativos a textos estándar a escala fija.


1798. Booleanas subtract no respetan copetes / zócalos modelados como sólidos separados pegados al mueble

Solución: excluir entidades marcadas como “zócalo/cornisa” por atributo antes de la operación.


1799. HtmlDialog sucumbe a “scroll jank” cuando se mezclan listeners scroll, resize y mousemove sin throttling

Solución: aplicar requestAnimationFrame o throttling a 30–60 FPS máximo.


1800. Exportar DXF envía todo a una sola capa “0” si el plugin no mapea capas SU → DXF explícitamente

Solución: implementar tabla de mapeo de capas (SketchUp layer → DXF layer) configurable por el usuario.
