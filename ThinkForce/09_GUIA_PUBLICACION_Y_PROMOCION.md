# PARTE I — PUBLICAR UN E-BOOK PROFESIONAL
## De Markdown a Amazon KDP en 30 Minutos

---

## PASO 1: PREPARAR EL CONTENIDO

### Formato recomendado
- Escribir todo en **Markdown** (archivos .md)
- Un archivo por capítulo o todo en uno
- Incluir encabezados jerárquicos (#, ##, ###)

### Herramientas gratuitas para convertir
| Herramienta | Comando | Resultado |
|------------|---------|-----------|
| **Pandoc** (gratis) | `pandoc libro.md -o libro.epub --toc` | EPUB con tabla de contenidos |
| **Calibre** (gratis) | Importar EPUB → Exportar MOBI/PDF | Múltiples formatos |
| **Kindle Create** (gratis) | Importar DOCX → Exportar KPF | Formato Amazon nativo |

### Flujo más rápido
```
libro.md → Pandoc → libro.epub → Amazon KDP
                                → Google Play Books
                  → Calibre → libro.pdf → Gumroad
                                        → Hotmart
```

---

## PASO 2: CREAR LA PORTADA

### Herramienta recomendada: Canva Pro ($12.99/mes)
1. Buscar "Book Cover" en plantillas
2. Dimensiones Amazon KDP: **1600x2560 px** (relación 1:1.6)
3. Tipografía grande y legible (mínimo 60pts para el título)
4. Máximo 3 colores
5. Evitar imágenes genéricas de stock

### Colores que funcionan en tech/IA
- Negro + Cyan (#38BDF8)
- Azul profundo (#1E3A5F) + Dorado (#FFD700)
- Gradiente oscuro + texto blanco
- Púrpura (#7C3AED) + Blanco

---

## PASO 3: INCLUIR ARCHIVOS ADJUNTOS (SKILLS)

| Plataforma | Cómo incluir archivos |
|-----------|----------------------|
| **Gumroad** | Subir como ZIP (libro.pdf + carpeta skills/) |
| **Hotmart** | Subir como "material complementario" |
| **Amazon KDP** | NO permite adjuntos → incluir link dentro del libro: "Descarga las Skills en: [tu-url]" |
| **Leanpub** | Permite carpeta ZIP adjunta |
| **Tu web propia** | Link directo a descarga |

### Recomendación: Usar Gumroad como hub de descarga
1. Crear producto en Gumroad ($0 = gratis o precio que quieras)
2. Subir el ZIP con las Skills
3. Dentro del libro (en Amazon, Google, etc.) incluir el link
4. Así tienes los archivos en un solo lugar y capturas emails

---

## PASO 4: PUBLICAR EN AMAZON KDP

1. Ir a **kdp.amazon.com** → crear cuenta (gratis)
2. "Bookshelf" → "Create New Title" → "Kindle eBook"
3. Completar información:
   - Título y subtítulo
   - Autor
   - Descripción (máx 4000 caracteres, usar viñetas)
   - Categorías: `Computers & Technology > Artificial Intelligence`
   - Keywords: 7 palabras clave (ej: "prompt engineering", "IA productividad")
4. Subir manuscrito (EPUB o DOCX)
5. Subir portada (JPG/PNG, 1600x2560px)
6. Establecer precio:
   - $2.99-$9.99 → regalía del **70%**
   - Fuera de ese rango → regalía del **35%**
7. Publicar → disponible en **24-72 horas**

---

## PASO 5: PUBLICAR EN GOOGLE PLAY BOOKS

1. Ir a **play.google.com/books/publish**
2. Crear cuenta de editor (requiere verificación)
3. Subir EPUB + portada
4. Establecer precio (Google cobra ~48%)
5. Publicar → disponible en **2-5 días**

---

## PASO 6: PUBLICAR EN GUMROAD (para venta directa + adjuntos)

1. Ir a **gumroad.com** → crear cuenta
2. "New Product" → "Digital Product"
3. Subir ZIP con: libro.pdf + libro.epub + carpeta skills/
4. Establecer precio (Gumroad cobra **10%**)
5. Personalizar página de producto
6. Publicar → disponible **inmediatamente**

# PARTE II — VIDEOS VIRALES EN TIKTOK
## Manual para Promover "Obliga a la IA a Pensar y Hazte Rico"

---

## PRINCIPIO FUNDAMENTAL

TikTok no vende libros. TikTok vende **CURIOSIDAD**.
Tu video debe hacer que la persona piense: "Necesito saber cómo hizo eso."

---

## FORMATO QUE FUNCIONA (Nicho Tech/IA)

| Elemento | Especificación |
|----------|---------------|
| **Duración** | 45-90 segundos (máximo completion rate) |
| **Estructura** | Hook (3s) → Problema (10s) → Solución (20s) → Resultado (10s) → CTA (5s) |
| **Texto en pantalla** | SIEMPRE. El 80% ve sin sonido |
| **Música** | Trending sounds, volumen bajo |
| **Cara a cámara** | Opcional. Screen recordings con narración funcionan en tech |
| **Frecuencia** | 1 video diario x 30 días mínimo |
| **Mejor horario** | 7-9 PM hora local del público objetivo |

## PRODUCCIÓN (con celular, sin inversión)

### Equipo mínimo
- Celular con cámara frontal (cualquiera post-2020 sirve)
- Buena iluminación natural (sentarse frente a una ventana)
- Trípode de celular ($5-10 en cualquier tienda)

### Apps gratuitas
| App | Para qué |
|-----|----------|
| **CapCut** | Edición de video + subtítulos automáticos |
| **Canva** | Thumbnails y gráficos animados |
| **OBS Studio** | Grabación de pantalla (para screen recordings) |
| **TikTok** | Publicación + efectos + música trending |

### Workflow de producción (15 minutos por video)
1. **3 min:** Escribir el guión (Hook + 3 puntos + CTA)
2. **5 min:** Grabar (máximo 2 tomas)
3. **5 min:** Editar en CapCut (cortes + subtítulos + música)
4. **2 min:** Subir a TikTok con hashtags y descripción

## ERRORES COMUNES A EVITAR

| Error | Por qué falla |
|-------|--------------|
| Videos de +3 minutos | TikTok penaliza baja completion rate |
| Solo hablar sin visual | La gente hace scroll si no hay algo visual interesante |
| Hook débil | Pierdes al espectador en los primeros 2 segundos |
| No poner subtítulos | 80% ve sin sonido |
| Publicar 1 vez por semana | El algoritmo necesita consistencia diaria |
| Vender en cada video | Destruye confianza. Ratio 80% valor / 20% venta |
| No responder comentarios | Los comentarios multiplican el alcance x3-5 |
